\begin{abstract}
二重時空理論の論理として、二重時空4値論理（D4L）を固定する。命題は許容ねじれ配置であり、同値に PGA 双ベクトル \(\Omega\) およびローター \(R=\exp\Omega\) である。測定は正規化高さ \(\Jnorm\in[-1,1]\) であり、崩壊は四つのラベル
\(\lvert T\rangle,\lvert U\rangle,\lvert F\rangle,\lvert B\rangle\)
を与える。スカラー結合子は \(\min/\max/-\) である。可換な重なりはパラメータ Killing 形式、非可換な干渉はねじれ双ベクトルの幾何交換子である。区間 \([-1,1]\) 上の二つの前順序が高さと飽和を分ける。これは Birkhoff--von Neumann の量子論理ではない。Hilbert 空間、Born 則、オーソモジュラー格子は D4L としては主張しない（兄弟構成は \texttt{dst-d4l-hilbert-ja.tex}）。以下に定理として書いた主張は Lean~4 で機械検証されている。
\end{abstract}

\section{位置づけ}
\label{sec:position}

二重時空理論は、すべての質量構成を六つのラピディティ
\((\alpha_a,\beta_a)_{a=1,2,3}\)
によって符号化する。各空間軸に、通常セクターのブーストと双対セクターの回転がある \cite{DST2025,Diophantine2026}。その対のすでに証明済みの不変量は符号付きの高さである。D4L は、許容配置そのものを命題とし、高さを観測量とし、高さの符号と飽和を四つの真理値として読む。

スカラー演算 \(\min/\max/-\) は分配的であり、PGA コアにすでに存在する幾何積を見ない。したがって幾何的な重なりと干渉は、第二の体系ではなく、同じ論理の一部である。疑似量子手法との比喩は発見法にすぎない：振幅・対・干渉・崩壊はあるが、\(\hbar\) もオーソモジュラー性の主張もない。

モジュールは並列トラックであり、\(\texttt{DstDiophantine.Basic}\) からは再エクスポートしない。Lean の入口は \(\texttt{DstDiophantine.Logic}\) である。

\section{ねじれと許容錐}
\label{sec:torsion}

\begin{definition}[ねじれスカラー]
\label{def:J}
ローター対に対して \(\Omega=R_{\rm usual}^\dagger R_{\rm dual}\) と書き、\(\Omega_{\rm biv}\) を主対数とする。本稿で用いるパラメータ形は
\begin{equation}
\label{eq:J-raw}
J = \frac12\sum_{a=1}^3\bigl(\alpha_a^2-\beta_a^2\bigr)
\end{equation}
である。古い草稿に現れる組み合わせ \(\frac1{16}B(\Omega_{\rm biv},\Omega_{\rm biv})\) は、標準的な生成子展開のもとで \eqref{eq:J-raw} と定数倍だけ異なる。ここでの有界性の主張は常に \(J\) と \(\Jnorm\) を指す \cite{Diophantine2026}。
\end{definition}

\begin{definition}[許容構成]
\label{def:admissible}
構成が\emph{許容}であるとは、すべての軸で
\[
\alpha_a\ge 0,\qquad \beta_a\ge 0,\qquad \alpha_a+\beta_a\le \frac{\pi}{2}
\]
が成り立つことである。
\end{definition}

切断 \(\pi/2\) は双対写像の反同期上限である：同一軸上の通常ラピディティと双対ラピディティは直角を超えて加算してはならない。

\begin{theorem}[ねじれ上限]
\label{thm:torsion-bound}
定義~\ref{def:admissible} の許容錐の上で
\[
|J|\le\Jbound,\qquad |\Jnorm|\le 1,
\]
ここで
\begin{equation}
\label{eq:Jnorm}
\Jnorm := \frac{8}{3\pi^2}\,J
\end{equation}
である。等号 \(|\Jnorm|=1\) は、すべての軸が純ブーストであるとき、またはすべての軸が純回転であるときに限り成り立つ。許容錐上の \(\Jnorm\) の像は区間 \([-1,1]\) 全体である。主枝条件 \(|\alpha_a+\beta_a|\le\pi/2\) だけを残して負のラピディティを許すと、上限は偽である。
\end{theorem}

コンパクト化 \(N\) に対する離散上限はより鋭い \cite{Diophantine2026}：
\[
|\Jnorm|\le\Bigl(\frac{4\lfloor N/4\rfloor}{N}\Bigr)^2.
\]
\(4\mid N\) のとき右辺は \(1\) であり、両符号が達成される。\(4\nmid N\) のとき、すべての許容点は厳密不等式 \(|\Jnorm|<1\) を満たす。

\section{振幅}
\label{sec:amp}

\begin{definition}[振幅]
\label{def:amp}
\emph{振幅}とは、許容連続ねじれ配置 \(p=(\alpha_a,\beta_a)\) である。
\[
\Omega(p)=\texttt{omegaTorsion}\,p,\qquad
R(p)=\texttt{rotorTorsion}\,p=\exp\Omega(p)
\]
と書く。測定と崩壊は
\[
\langle p\rangle:=\Jnorm(p),\qquad
\mathrm{collapse}(p):=\texttt{ofParams}\,p
\in\{\lvert T\rangle,\lvert U\rangle,\lvert F\rangle,\lvert B\rangle\}
\]
である。随伴は通常–双対スワップ \(p^\dagger=\texttt{daggerParams}\,p\) である。
\end{definition}

\begin{theorem}[随伴]
\label{thm:adjoint}
スワップは対合であり、観測量の符号を反転する：
\( (p^\dagger)^\dagger=p \) かつ \(\langle p^\dagger\rangle=-\langle p\rangle\)。
すべてのラベルはある振幅によって実現される。
\end{theorem}

四つの名前は随伴のもとで互いの関数ではない：最深の \(\lvert B\rangle\) は \(\lvert F\rangle\) へ、内部の \(\lvert B\rangle\) は \(\lvert U\rangle\) へ行く。

\section{四状態}
\label{sec:states}

\begin{definition}[D4L 状態]
\label{def:states}
\(\Jnorm\in[-1,1]\) の上で
\begin{align*}
\lvert T\rangle &\colon \Jnorm = 0
  &&\text{完全な通常–双対バランス、}\\
\lvert U\rangle &\colon 0 < \Jnorm < 1
  &&\text{ブースト優勢・未飽和、}\\
\lvert F\rangle &\colon \Jnorm = +1
  &&\text{全軸が純ブースト、}\\
\lvert B\rangle &\colon -1\le \Jnorm < 0
  &&\text{回転優勢。最深点 \(\Jnorm=-1\) を含む。}
\end{align*}
\end{definition}

正の極端は False と名付けられた単元であり、負の極端は Both の内部に残す。これは論理上の規約であり、錐の欠落ではない：両極端は存在し、一意である。混合極端——ある軸がブースト、別の軸が回転——は決して \(|\Jnorm|=1\) に届かない。飽和には、すべての軸が同じ向きに揃うことが必要である。

\begin{theorem}[極端ラベル]
\label{thm:extremal}
許容配置の上で、\(\mathrm{collapse}(p)=\lvert F\rangle\) であることと \(p\) が純双曲であることは同値であり、\(\Jnorm(p)=-1\) であることと \(p\) が純楕円であることは同値である。
\end{theorem}

内部の \(\lvert B\rangle\) は範囲であり、単一の固定点ではない。第~\ref{sec:potential}節の大規模ポテンシャルの安定点は壁 \(\Jnorm=-1\) である。

\section{結合子}
\label{sec:conn}

\begin{definition}[論理演算]
\label{def:ops}
符号付き高さの上で
\[
\neg j = -j,\qquad
j\wedge k = \min(j,k),\qquad
j\vee k = \max(j,k)
\]
とする。否定は通常–双対スワップ
\((\alpha_a,\beta_a)\mapsto(\beta_a,\alpha_a)\)
であり、\(J\mapsto -J\)、したがって \(\Jnorm\mapsto-\Jnorm\) を誘導する。
\end{definition}

\begin{theorem}[非爆発]
\label{thm:nexplosion}
すべての \(j\in[-1,1]\) に対して
\[
j\wedge\neg j = -|j|\le 0
\]
である。したがって \(p\wedge\neg p\) は \(\lvert T\rangle\) または \(\lvert B\rangle\) であり、決して \(\lvert F\rangle\) に飽和しない。De Morgan 双対と分配則は、\(\mathbb{R}\) 上の \(\min/\max\) におけるものと同じである。
\end{theorem}

状態レベルの否定は四つのラベルの関数ではない：最深の \(\lvert B\rangle\) は \(\lvert F\rangle\) へ、内部の \(\lvert B\rangle\) は \(\lvert U\rangle\) へ行く。

スケール変形した合接は softmin
\[
a\land_\beta b =
-\frac1\beta\log\bigl(e^{-\beta a}+e^{-\beta b}\bigr),\qquad \beta>0
\]
である。\(\beta\to\infty\) で \(\min(a,b)\) を回復する。有限の \(\beta>0\) では softmin は \(\min\) より真に小さい。小さな \(\beta\) のレジームは二値的なハード判定ではない。

\section{二つの順序、Belnap FOUR ではない}
\label{sec:order}

\begin{definition}
\(\mathbb{R}\) の上で、そして制限により \([-1,1]\) の上で
\[
j\preceq_\tau k \iff j\le k,
\qquad
j\preceq_\iota k \iff \lvert j\rvert\le\lvert k\rvert
\]
とする。前者は高さ（ブースト対回転）の順序、後者は情報（飽和）の順序である。
\end{definition}

\begin{theorem}[情報の底と頂]
\label{thm:info}
\([-1,1]\) の上で、\(j=0\) は一意の情報の底であり、情報の頂はちょうど壁 \(j=\pm 1\) である。同値に、情報の底はラベル \(\lvert T\rangle\)、二つの頂は \(\lvert F\rangle\) と最深の \(\lvert B\rangle\) である。
\end{theorem}

内部の \(\lvert B\rangle\) は情報順序で最深の \(\lvert B\rangle\) より真に小さい。ラベルは Belnap の \(\{\bot,t,f,\top\}\) と一致しない。複格子同型は主張しない。

\section{幾何演算}
\label{sec:geo}

\begin{definition}[重なりと干渉]
\label{def:geo}
\[
\langle p\mid q\rangle := \texttt{killingForm}\,p\,q
= 8\sum_{a=1}^3\bigl(\alpha_a\alpha'_a-\beta_a\beta'_a\bigr),
\qquad
[\Omega(p),\Omega(q)] := \Omega(p)\Omega(q)-\Omega(q)\Omega(p).
\]
ローター合成 \(R(p)R(q)\) は PGA における積である。Baker--Campbell--Hausdorff 公式を通して第三のねじれ配置へは引き戻さない。
\end{definition}

\begin{theorem}[対と非可換性]
\label{thm:geo}
重なりは対称であり、\(\langle p\mid p\rangle=16\,J(p)\)、同値に \(\Jnorm(p)\) の定数倍である。異軸のねじれ双ベクトルは可換である必要はない：\(p\) が軸 \(0\) の純ブースト、\(q\) が軸 \(1\) の純回転ならば \([\Omega(p),\Omega(q)]\ne 0\)。同軸の双曲生成子と循環生成子は可換なので、対応する一軸干渉は消える。
\end{theorem}

重なりは Born 確率ではない。sandwich 評価 \(R(p)\,v\,R(p)^\sim\) は重力チャート層から独立に再掲する。退化二次形式の保存は主張しない。幾何合成は PGA 積として結合的であり、格子演算であることは主張しない。

\section{スケールとポテンシャル}
\label{sec:potential}

\(\lambda>0\) をスケールパラメータ、\(\alpha>0\) を結合とする。有効ポテンシャルは
\begin{equation}
\label{eq:Vlam}
V_\lambda(J) = -\cos(2\pi J) + \frac{\alpha}{\lambda}\, U(J)
\end{equation}
であり、書かれた候補は
\[
U_{\mathrm{piece}}(J)=\begin{cases}0&J<0\\ J^2&J\ge 0\end{cases},\qquad
U_{\mathrm{smooth}}(J)=\tfrac12\bigl(J+|J|\bigr)^2
\]
である。この二つの関数は \(\{J>0\}\) で定数倍だけ異なる。勾配流は \(\dot J=-\partial V_\lambda/\partial J\) である。

\begin{theorem}[大規模骨格]
\label{thm:Vinf}
\(\lambda\to\infty\) のとき \(V_\lambda\) は \(V_\infty(J)=-\cos(2\pi J)\) に収束する。臨界点は \(k\in\mathbb{Z}\) に対する \(J=k/2\) である。\([-1,1]\) 上の局所安定点は \(\{-1,0,+1\}\)、鞍点は \(\{\pm 1/2\}\) である。流れ \(\dot J=-V_\infty'(J)\) の盆地は
\[
(-1,-1/2)\to -1,\qquad
(-1/2,1/2)\to 0,\qquad
(1/2,1)\to +1
\]
である。
\end{theorem}

したがって \(\lvert U\rangle\) はラベルであり、アトラクタではない。
負ねじれ側のアトラクタ盆地は区間 \([-1,-1/2)\) に限る。
\([-1,0)\) 全体ではない。

\begin{theorem}[書かれた \(U\) は \(B\) 井戸を残す]
\label{thm:Uwritten}
\(\{J<0\}\) では両方の書かれた候補が消えるので、負半直線全体で \(V_\lambda=V_\infty\) である。とくにすべての \(\lambda>0\) で \(V_\lambda''(-1)=4\pi^2>0\) である。書かれた \(U\) が \(\Jnorm=-1\) の局所最小を壊す臨界スケールは存在しない。
\end{theorem}

したがって小スケールでの四値から二値への収縮は、書かれた \(U\) をもつ \eqref{eq:Vlam} の定理ではない。線形バイアス \(\gamma J\) を最小化すると、\(\gamma\) と逆符号の側が下がる：\(\gamma>0\) は負ねじれを安定化する。

スケール \(\lambda\) は CGA dilation や増幅写像 \(\texttt{scaleTorsion}\) とは同一視しない。

\section{自己言及}
\label{sec:godel}

\(G\) をゲーデル文とする：「\(G\) はこの体系で証明可能ではない」。D4L では、証明可能性を同期 \(\Jnorm\to 0\)、すなわち \(\lvert T\rangle\) への駆動として読む。一意の全ブースト世界に坐ることを禁じられた文に対する誠実な制約は
\[
\Jnorm(G)<1
\]
だけである。定理~\ref{thm:Vinf} の大規模流のもとで、この制約は \(G\) を \(\lvert U\rangle\) または \(\lvert B\rangle\) に残す。連言は爆発しない：二つの非正の高さは非正のままである。

これは意味論の変更であり、ゲーデルの定理が古典算術において失敗することの証明ではない。負ねじれセクター上の完全性の話も、許容ローターの読みであって、一次ペアノ算術の内部でのヒルベルト計画の完了ではない。

\section{D4L が示すこと・示さないこと}
\label{sec:claims}

\begin{itemize}[leftmargin=1.4em]
  \item \emph{示す}のは、許容ねじれ配置を命題の担体とし、\(\Jnorm\) を観測量とすることである。
  \item \emph{示す}のは、\([-1,1]\) を四つの名前付き状態へ分割し、許容錐上で両壁が達成されることである。
  \item \emph{示す}のは、否定を幾何的にすることである：通常–双対スワップ。
  \item \emph{示す}のは、代数ですでに証明済みの可換な対と非可換な干渉項である。
  \item \emph{示す}のは、\([-1,1]\) 上の二つの前順序による高さと飽和の分離である。
  \item \emph{示す}のは、\(p\wedge\neg p\) を \(\lvert F\rangle\) の外に保つことである。
  \item \emph{示さない}のは、D4L としての Hilbert 空間、Born 則、オーソモジュラー格子の構成である。双対セクターの兄弟である $\mathbb{C}^2$ とその部分空間格子は \texttt{dst-d4l-hilbert-ja.tex} に別記する。四ラベルや $\min/\max$ とは同一視しない。
  \item \emph{示さない}のは、\(\lambda\) と CGA dilation や \(\texttt{scaleTorsion}\) の同一視である。
  \item \emph{示さない}のは、書かれたポテンシャル \(U\) からの四値から二値への崩壊である。
  \item \emph{示さない}のは、古典算術におけるゲーデルの定理の反証である。
  \item \emph{示さない}のは、\([\Omega(p),\Omega(q)]\ne 0\) のとき \(R(p)R(q)\) をねじれ配置へ引き戻すことである。
  \item \emph{示さない}のは、生の \(J\) を \([-1,1]\) の値と同一視することである。その区間は \(\Jnorm\) のものであり、生の天井は \(\Jbound\) である。
\end{itemize}

Lean のモジュールは \(\texttt{Amplitude}\)、\(\texttt{TruthValue}\)、\(\texttt{Connective}\)、\(\texttt{Interpretation}\)、\(\texttt{Order}\)、\(\texttt{Geometric}\)、\(\texttt{Potential}\) である。
