\begin{abstract}
一般相対性理論は、重力を単一の時空連続体の曲率として見ることを教えてきた。惑星の運動、光の遅れ、ブラックホールの鳴動は、その教えの成果である。しかし連続体がなぜ曲がるのか、なぜ同一の現象が加速度のもとで慣性として現れるのかは、そこでは問われない。本稿は連続体を原始的対象とすることを拒んで、その問いに答える。時空は自律的な舞台ではない。各質量粒子は、ミンコフスキーフレームの対を運ぶ。一つはわれわれが生き、測る通常時空であり、もう一つはそれに対して時間反転した双対時空で、間隔は同じである。重力とはその対のねじれであり、粒子自身に属する不整合である。

この描像から直ちに二つのことが従う。球対称質量の外側の幾何は、曲率を原始的対象とせず、二つのフレームの不整合として回復される。重力と慣性は同一の現象になる。自由落下は二つのフレームが揃った状態であり、加速度は、周囲の質量が源であるときに重力と呼ぶ、同じ不整合である。もしこの存在論が正しければ、世界の幾何は物質に先立たない。それはスピンや電荷と同様、粒子の属性であり、天空に見える曲率は双対フレームの集合的なねじれである。
\end{abstract}

\section{はじめに}
\label{sec:introduction}

1915年の誕生以来、一般相対性理論はわれわれがもつ重力記述のうち最も成功したものである。水星の近日点、光の遅れ、重力波、ブラックホールの撮像は、すべてそれを物語る。しかし哲学的な不安は残る。なぜ物質は時空を曲げ、なぜ曲がった時空が物質の運動を支配するのか。アインシュタイン方程式は重力がどのように働くかを極めて精密に教える。連続体がなぜ曲がるのかは、そこでは問われない。この不安はマッハの原理と対峙するといっそう鋭くなる。物体の慣性は宇宙の物質の総体によって決まるべきであるのに対し、一般相対性理論は時空を、完全な空虚さの中でも存在しうる独立した連続体として扱う。

この隙間を埋めようとする一世紀の試みは、連続体そのものには手を触れなかった。時空は先験的に滑らかな多様体とされ、重力は計量の平坦さからのずれである。

本稿はその原始的対象を拒む。共有される単一の時空は存在しない。各質量粒子は、独自のミンコフスキーフレームの対を運ぶ。一つはわれわれが生き、測る通常時空である。もう一つは双対時空であり、前者に対して時間反転しており、間隔は同じである。重力と慣性は背景の曲率ではない。ある粒子に別の粒子との並行を求めるとき、これら二つのフレームが不整合になることである。

転換は存在論的である。標準描像では、時空が物質に運動を教え、物質が時空に曲がり方を教える。ここには自律的な時空は全くない。時空と呼ばれる自由度は、スピンや電荷と同様、粒子の内部属性である。巨視的世界の見かけの曲率は、隣り合う粒子の集合的な不整合である。

直ちに二つの帰結が従い、それらは数式を書く前に述べられる。第一に、球対称質量の外側の幾何は、曲率を原始的対象とせず、二つのフレームの不整合として回復される。第二に、重力と慣性は同一の現象である。自由落下は二つのフレームが揃った状態である。加速度はその揃いを破り、生じる不整合が慣性力である——周囲の質量が源であるときに重力と呼ぶ、同じねじれである。

これは一般相対性理論の修正ではない。提案する完成である。連続体は有用な巨視的フィクションのままである一方、時空の自由度は対をなし粒子局所的なものとして扱われる。

本稿はその順序で進む。第\ref{sec:math}節と第\ref{sec:kinematics}節で二つのセクターと、それらを動かす変換を導入する。第\ref{sec:gravity}節で重力をその不整合として定義し、球対称質量の外側を回復する。第\ref{sec:unified}節では同じ不整合から慣性を読み、等価原理を要請ではなくする。その描像を手にしたうえで、後続の節は幾何を強場域、核と原子の尺度、電磁気、銀河へと運ぶ。それらの読みは描像の上に築かれるものであり、描像の基礎ではない。第\ref{sec:conclusions}節では存在論に立ち返り、それを試しうる観測へ戻る。

\section{数学的基礎：16次元双四元数代数}
\label{sec:math}

二重時空理論全体は、ミンコフスキー時空（符号 $(-,+,+,+)$）上のクリフォード幾何代数 $\mathrm{Cl}(3,1)$ と標準的に同型である双四元数（二重四元数とも呼ばれる）の16実次元代数の中に構築される。この代数は、すべての質量粒子に内在的に付随する単一代数構造の中に、通常と双対という二つの可換なミンコフスキー時空の完全なコピーを自然に収容する。

\subsection{双四元数代数}

まずハミルトンの四元数代数の二つの独立したコピーから出発する。
\begin{itemize}
  \item 生成子 $i,j,k$ が $i^2=j^2=k^2=-1$, \ $ij=k$, \ $ji=-k$（巡回）を満たす主四元数、
  \item 生成子 $I,J,K$ が同一の規則 $I^2=J^2=K^2=-1$, \ $IJ=K$, \ $JI=-K$（巡回）を満たす従四元数。
\end{itemize}
完全な双四元数代数はテンソル積 $\mathbb{H} \otimes_{\mathbb{R}} \mathbb{H}$ であり、二つの集合は厳密に可換である。
\[
iI = Ii,\; iJ = Ji,\; iK = Ki,\; jI = Ij,\; \dots
\]
得られる16個の実線形独立基底は
\[
1,\; i,\; j,\; k,\; I,\; J,\; K,\; iI,\; iJ,\; iK,\; jI,\; jJ,\; jK,\; kI,\; kJ,\; kK.
\]

\subsection{Cl(3,1) との明示的同型}

次の1次（ベクトル）生成子の同定により、代数は $\mathrm{Cl}(3,1)$ と同型である。
\begin{align*}
  e_0 &= j,                    & &\text{（時間様基底ベクトル）}\\[4pt]
  e_1 &= kI, \quad e_2 = kJ, \quad e_3 = kK & &\text{（空間様基底ベクトル）},
\end{align*}
これは直ちに定義関係
\[
e_0^2 = -1, \quad e_1^2 = e_2^2 = e_3^2 = +1, \quad \{e_\mu,e_\nu\} = 0 \;\; (\mu \neq \nu).
\]
を満たす。高次の元は標準的なクリフォード積に従う。特に：
\begin{alignat*}{3}
  &\text{2次（バイベクトル）:}  &\quad& e_0e_1 = iI, \;\; e_0e_2 = iJ, \;\; e_0e_3 = iK, \\
  &&& e_3e_2 = I,   \;\; e_1e_3 = J,   \;\; e_2e_1 = K, \\[6pt]
  &\text{3次（トライベクトル）:} && e_1e_2e_3 = k, \;\; e_0e_3e_2 = jI, \;\; e_0e_1e_3 = jJ, \;\; e_0e_2e_1 = jK, \\[6pt]
  &\text{擬スカラー:}        && e_0e_1e_2e_3 = i.
\end{alignat*}
右乗算 $i$ による時間反転の下で補完的となる「双対」基底は
\[
\tilde{e}_0 = k = e_1e_2e_3, \quad \tilde{e}_1 = jI = e_0e_3e_2, \quad \tilde{e}_2 = jJ = e_0e_1e_3, \quad \tilde{e}_3 = jK = e_0e_2e_1,
\]
で生成され、以下で導入する双対時空表示を与える。

この明示的同型により、16次元双四元数代数はアドホックな構成ではなく、4次元ミンコフスキー時空の幾何的に自然なクリフォード代数であることが明らかになる。それは通常セクターと双対セクターを区別しつつ完全なローレンツ構造を保つ内在的デュアリティで豊かになる。

クリフォード代数形の見かけの不規則性。例えば $j$ だけが唯一の時間様ベクトル生成子であることや、空間基底が交差項優勢の $kI,kJ,kK$ であることは偶然ではない。二つの時間反転したミンコフスキー時空のコピーを同時に符号化する構造の中で、3次元物理空間の完全な回転対称性を保つために正確に存在する。この微妙な非対称性が、双対写像 $X \mapsto Xi$ が時間の矢を反転させても空間等方性を破らないことを可能にし、等価原理と、粒子内在的な双対フレーム間の相対ずれとしての重力学的ねじれの創発のための代数的基礎を与える。

\subsection{粒子内在的な双対時空構造}

各粒子は、双四元数代数内に符号化されたコンパクト化されたミンコフスキー時空の対を内在的に運ぶと仮定される。
\begin{itemize}
  \item \textbf{通常時空：} 次の形のベクトルで表される
  \[
  X = ct \, j + x \, kI + y \, kJ + z \, kK,
  \]
  ミンコフスキーノルムは
  \[
  X^2 = -(ct)^2 + x^2 + y^2 + z^2.
  \]

  \item \textbf{双対時空：} 次の形のベクトルで表される
  \[
  X' = ct' \, k + x' \, jI + y' \, jJ + z' \, jK,
  \]
  同一のミンコフスキーノルム
  \[
  X'^2 = -(ct')^2 + x'^2 + y'^2 + z'^2.
  \]
\end{itemize}
二つの時空は双対写像
\[
X' = X i,
\]
で結ばれ、時間の矢を反転させる。
\[
(ct \, j) i = ct \, (j i) = -ct \, k,
\]
ミンコフスキーノルムは保たれる。$\mathrm{Cl}(3,1)$ の擬スカラー $i = e_0 e_1 e_2 e_3$ はすべての1次ベクトルと反可換（$X \in \mathrm{Cl}(3,1)$ に対し $i X = -X i$）であり $i^2 = -1$ を満たすため、ノルムは次のように変換される。
\[
X'^2 = (X i)(X i) = X (i X) i = -X (X i) i = -X^2\, i^2 = -X^2 \cdot (-1) = X^2.
\]
この双対構造はすべての粒子に内在的である。通常時空は標準的運動学を支配し、双対時空は重力と慣性の存在下で動学的に関連する補完的自由度を符号化する。二つの時空の存在により、ローレンツ変換、平行移動、そして重力の本性のより豊かな幾何解釈が可能となる。

\section{運動学的構造：ローター、ブースト、平行移動}
\label{sec:kinematics}

本節では理論の運動学的枠組みを展開する。通常セクターのローレンツブーストと双対セクターの楕円回転は、六つのバイベクトル $\{i\Gamma_a,\Gamma_a\}$ によって生成される。同軸対は可換であり、異軸対は必ずしもそうではない。ブーストは平方が $+1$ となるバイベクトルから生じ、ローターの $\cosh$/$\sinh$ 展開を与える。

\subsection{通常時空におけるローター}

運動学的構造を示すため、ラピディティ $\phi$ の $x$ 方向ローレンツブーストを考える。生成バイベクトルは $iI$ であり $(iI)^2 = i^2 I^2 = (-1)(-1) = +1$ を満たす。一般に通常セクターのブースト生成子 $iI,iJ,iK$ は平方が $+1$ であり、双対セクターの回転生成子 $I,J,K$ は平方が $-1$ である。同じ $I,J,K$ は通常ミンコフスキーフレームの空間バイベクトル（$e_3e_2=I$、$e_1e_3=J$、$e_2e_1=K$）であり、独立な第二の $\mathfrak{so}(3)$ コピーを与えるのではない。

対応するブーストローターはしたがって
\[
R_\text{usual} = \exp\!\left( \frac{\phi}{2} iI \right).
\]
生成子の正の平方により、指数は双曲関数へと自然に展開される。
\[
R_\text{usual} = \cosh \frac{\phi}{2} + iI \sinh \frac{\phi}{2}.
\]
このローターをサンドイッチ積で時空ベクトル $X = ct \, j + x \, kI + \cdots$ に適用すると、正準ローレンツ変換が得られる。
\begin{align*}
ct' \, j + x' \, kI &= R_\text{usual} \, X \, R_\text{usual}^\dagger \\
&= \left[ \cosh\frac{\phi}{2} + iI \sinh\frac{\phi}{2} \right] (ct \, j + x \, kI) \left[ \cosh\frac{\phi}{2} - iI \sinh\frac{\phi}{2} \right] \\
&= (\gamma ct + \gamma v x) \, j + (\gamma x + \gamma v ct) \, kI,
\end{align*}
ここで $\gamma = \cosh \phi$, $v/c = \tanh \phi$。通常ミンコフスキーベクトルの空間回転は、双対セクターの楕円ローターを生成するのと同じ $\Gamma_a\in\{I,J,K\}$ によって生成され、余分なローレンツコピーではない。

\subsection{完全ローター}

この基底上の最も一般の六パラメータ指数は
\[
R_\text{total} = \exp\left( \frac{\phi_1}{2} iI + \frac{\phi_2}{2} iJ + \frac{\phi_3}{2} iK + \frac{\theta_1}{2} I + \frac{\theta_2}{2} J + \frac{\theta_3}{2} K \right),
\]
である。ここでパラメーター $\phi_a$ は通常セクターのブーストを、$\theta_a$ は双対セクターの回転を支配する。第\ref{sec:math}節の空間バイベクトルを $\Gamma_1=I$, $\Gamma_2=J$, $\Gamma_3=K$ と書く。因数分解 $R_{\mathrm{total}}=R_{\mathrm{usual}}R_{\mathrm{dual}}$ は自動的ではない。二つの和項が可換であることを要する。同軸では可換である：$[i\Gamma_a,\Gamma_a]=0$。したがって
\[
\exp\Bigl(\tfrac{\phi}{2}i\Gamma_a+\tfrac{\theta}{2}\Gamma_a\Bigr)
=\exp\bigl(\tfrac{\phi}{2}i\Gamma_a\bigr)\,\exp\bigl(\tfrac{\theta}{2}\Gamma_a\bigr).
\]
異軸では必ずしもそうではない。とくに $[iI,J]\neq 0$ であり、六パラメータ指数は、その追加の仮定なしには一軸ローターの積へ因数分解されない。以下では $R_{\mathrm{total}}=R_{\mathrm{usual}}R_{\mathrm{dual}}$ と書くときは常に単一軸上で働く。

単一軸上で幾何的意味をより明瞭にするため、大きさと方向を分離するバイベクトル形のローターを導入する。

通常時空の単位ブーストバイベクトルを
\[
\hat{p} = p_1 \, iI + p_2 \, iJ + p_3 \, iK, \qquad \hat{p}^2 = +1,
\]
と定義する。$\hat{p}$ は正規化（$|\hat{p}| = 1$）され、$\phi = \sqrt{\phi_1^2 + \phi_2^2 + \phi_3^2}$ は全ラピディティ（方向は $p_a = \phi_a / \phi$ に符号化）である。

同様に双対時空の単位回転バイベクトルを
\[
\hat{q} = q_1 \, I + q_2 \, J + q_3 \, K, \qquad \hat{q}^2 = -1,
\]
と定義する。$\hat{q}$ は正規化（$|\hat{q}| = 1$）され、$\theta = \sqrt{\theta_1^2 + \theta_2^2 + \theta_3^2}$ は全双対回転角（方向は $q_a = \theta_a / \theta$）である。

完全ローターは次のバイベクトル指数形をとる。
\[
R_\text{total} = \exp\!\left( \frac{\phi}{2} \hat{p} + \frac{\theta}{2} \hat{q} \right).
\]
$\hat{p}$ と $\hat{q}$ が単一軸上で整列するとき指数は因数分解され、$R_{\mathrm{total}}=R_{\mathrm{usual}}R_{\mathrm{dual}}$ となり、
\[
R_\text{usual} = \exp\!\left( \frac{\phi}{2} \hat{p} \right)
= \cosh\frac{\phi}{2} + \hat{p} \sinh\frac{\phi}{2},
\]
\[
R_\text{dual} = \exp\!\left( \frac{\theta}{2} \hat{q} \right)
= \cos\frac{\theta}{2} + \hat{q} \sin\frac{\theta}{2}.
\]
である。六つの実パラメーターは、通常セクターのラピディティ $\phi$ と単位ブースト方向 $\hat{p}$、および双対セクターの回転角 $\theta$ と単位軸 $\hat{q}$ のままである。因数分解は以下では生成子が可換なときにのみ用いる。

\subsection{サンドイッチ積}

ヴァーソル形式はこれらの変換を適用する簡潔な手段を与える。時空事象を表す任意の双四元数マルチベクトル $X$ に対し、変換後のベクトルは
\[
\tilde{X} = R_\text{total} \, X \, R_\text{total}^\dagger.
\]
この単一の操作はミンコフスキーノルム（$X^2 = \tilde{X}^2$）を保ち、通常成分と双対成分の双方に一貫して作用し、ブーストと回転を一つの代数的表現に継ぎ目なく統合する。行列や座標依存の機構は不要であり、幾何は代数の内に内在的に展開される。

\section{双対時空間のねじれ不整合としての重力}
\label{sec:gravity}

本中心節では、重力が時空の曲率でも外力でもなく、すべての質量粒子が内在的に運ぶ通常時空と双対時空の間のねじれ不整合であることを確立する。クリストッフェル記号、リーマンテンソル、連続多様体は原始的対象ではない。ねじれは粒子局所的な双対ローター間の相対回転角である。パラメータ空間の $J$ はワイツェンベックスカラー $T$ とは別物である。

\subsection{ねじれ不整合ローターの定義}

ねじれ不整合ローターは
\[
\Omega = R_\text{usual}^\dagger R_\text{dual}.
\]
と定義される。

ダガー操作は双四元数代数におけるローターの標準的共役逆である。
\[
R_\text{usual}^\dagger = \exp\!\left( -\frac{\phi}{2} \hat{p} \right)
= \cosh\frac{\phi}{2} - \hat{p} \sinh\frac{\phi}{2}.
\]
形式的には単純な共役だが、このダガーは二重時空枠組みにおいて特別な意味を持つ。$\sinh$ 項の前の負符号は双対写像に内在する時間反転を正確に符号化する。擬スカラー $i$ は4次でありしたがってバイベクトルと可換であるため、右乗算 $i$ はブースト生成子に対して
\[
\hat{p}\, i = - (p_1 I + p_2 J + p_3 K) \equiv -\hat{q}',
\qquad (\hat{p}\, i)^2 = -1,
\]
と作用する。ここで $\hat{q}' \equiv p_1 I + p_2 J + p_3 K$ は双対セクターにおける単位回転生成子である。同値に $\hat{p} = \hat{q}'\, i$ であり、逆通常ローターは厳密な書き換え
\[
R_\text{usual}^\dagger = \cosh\frac{\phi}{2} - \hat{q}'\, i\, \sinh\frac{\phi}{2}.
\]
を許す。標準的恒等式 $\cosh(\phi/2) = \cos(i\phi/2)$ および $\sinh(\phi/2) = \sin(i\phi/2)/i$ を用いると、これは解析接続（$\phi \to i\phi$）された三角関数形
\[
R_\text{usual}^\dagger = \cos\!\left(\frac{i\phi}{2}\right) - \hat{q}'\, \sin\!\left(\frac{i\phi}{2}\right),
\]
を与え、ダガー操作が通常時空の双曲幾何と双対時空の楕円幾何を橋渡しすることを示す。実引数に対する $\cosh$ と $\cos$ の等価ではなく、双対写像 $X \mapsto X i$ を横断するブーストローターの一意な解析接続である。

相対ローター $\Omega = R_\text{usual}^\dagger R_\text{dual}$ はこの橋渡しを操作的に実現する。ダガーは通常時空の双曲ブースト構造を一時的に「分解」し（符号反転を通じて双対写像を誘起し）、続く $R_\text{dual}$ との乗算が結合対象を「再構成」し、相対的ずれを明示する。この「分解--再構成」過程を通じて、通常時空と双対時空のねじれ不整合が代数的に抽出され、この不整合が二重時空枠組みにおける重力の本質をなす。

自由落下は、この不整合が消える状態である。$R_{\mathrm{usual}}$ のユニタリ性は鋭い判定を与える。$\Omega=1$ となるのは二つのローターが一致するとき、すなわち $R_{\mathrm{dual}}=R_{\mathrm{usual}}$ のときに限る。反同期 $R_{\mathrm{dual}}=R_{\mathrm{usual}}^\dagger$ は別の条件である。単一軸上では両バイベクトル係数の消滅を強制するので、非自明な純ブーストはそれを満たさない。質量--エネルギーは $\Omega=1$ からのずれの物理的コストとして読む。ローターそのものは偶部分代数の単元である。対数 $\Omega_{\mathrm{biv}}=\log\Omega$ は $\mathfrak{so}(3,1)$ に値をとり、六つの生成子 $\{i\Gamma_a,\Gamma_a\}$ は一つのローレンツコピーを張る。十二次元直和 $\mathfrak{so}(3,1)\oplus\mathfrak{so}(3,1)$ ではない。

関連するねじれバイベクトルは
\[
\Omega_\text{biv} = \log \Omega \in \mathfrak{so}(3,1),
\]
恒等元の単連結近傍における主枝である。本論文を通じて小不整合のレジームは $\Omega \approx 1$ であり、そこで $\Omega_\text{biv}$ は一意に定まる。この近傍の外にある位相的に異なる枝は、ここで提示する動力学では用いない。

\subsection{双対ねじれからのローレンツ不変スカラー}

$\mathfrak{so}(3,1)$（ベクトル表現）上のキリング形式は
\[
B(X,Y) = 4\,\mathrm{Tr}(X Y).
\]
\S\ref{sec:kinematics} の 2 次空間バイベクトルをまとめて $\Gamma_a$（$a=1,2,3$）と書き、$\Gamma_1 = I$, $\Gamma_2 = J$, $\Gamma_3 = K$ とする（\S\ref{sec:math} のクリフォード同型 $e_3e_2 = I$, $e_1e_3 = J$, $e_2e_1 = K$ に対応）。通常時空のブースト生成子は $i\Gamma_a$、双対セクターの回転を生成するのは $\Gamma_a$ である。キリング形式を評価すると $B(i\Gamma_a, i\Gamma_a) = +8$, $B(\Gamma_a, \Gamma_a) = -8$ となり、ローレンツ符号を完璧に再現する。同軸生成子は可換であり $[i\Gamma_a,\Gamma_a]=0$ である。異軸の交換子は必ずしも消えない。

半角展開 $\Omega_\text{biv}=\sum_a\bigl(\frac{\alpha_a}{2}i\Gamma_a+\frac{\beta_a}{2}\Gamma_a\bigr)$ と書く。六つの生成子は $\mathfrak{so}(3,1)$ の一つのコピーを張る。並進と合わせて、周囲代数はポアンカレ候補 $\mathfrak{iso}(3,1)\cong\mathfrak{so}(3,1)\ltimes\mathbb{R}^{3,1}$ である。このとき
\[
B(\Omega_\text{biv},\Omega_\text{biv})=2\sum_{a=1}^3(\alpha_a^2-\beta_a^2).
\]
本論文を通じて不整合を測るスカラーは
\begin{equation}
\label{eq:J-def}
J=\frac12\sum_{a=1}^3(\alpha_a^2-\beta_a^2),
\end{equation}
であり、この展開の下で $\frac1{16}B(\Omega_\text{biv},\Omega_\text{biv})$ の4倍である。あわせて $\Jnorm=\frac8{3\pi^2}J$ と書き、符号なしねじれ質量を $M=\frac12\sum_a(\alpha_a^2+\beta_a^2)$、同じ正規化 $\Mnorm=\frac8{3\pi^2}M$ とする。

$J$ の符号は通常の引力重力と双対支配の斥力を区別する。通常時空ブーストが支配すれば $J>0$ であり力は引力である。双対回転が支配すれば $J<0$ であり力は斥力である。二つのセクターの入れ替え $\alpha\leftrightarrow\beta$ は $J\mapsto -J$ を送り、$M$ を不変に保つ。

三つの消滅条件を混同してはならない。$M=0$ ならば $J=0$ である。すべてのラピディティが消え、これが真空である。逆は偽である。通常と双対のラピディティが等しければ $J=0$ かつ $M>0$ となり——釣り合い質量状態——単一軸上ではなお $\Omega\neq 1$ である。したがって $\Omega=1$、$J=0$、$M=0$ は三つの相異なる物理的状況である。自由落下としての重力は $\Omega=1$ であり、$J$ の消滅ではない。

代数は非有界な不整合を許さない。許容配置——各軸で非負ラピディティかつ $\alpha_a+\beta_a\le\pi/2$——においては $|J|\le\Jbound$ かつ $|\Jnorm|\le 1$、同様に $0\le\Mnorm\le 1$ である。この錐上での $\Jnorm$ の像は区間 $[-1,1]$ 全体である。等式 $|\Jnorm|=1$ は、純双曲配置（すべての軸で $\alpha_a=\pi/2$, $\beta_a=0$）または純楕円配置（すべての軸で $\alpha_a=0$, $\beta_a=\pi/2$）のときに限る。符号制限のない主枝条件 $|\alpha_a+\beta_a|\le\pi/2$ だけでは足りない。有界は失敗する。

\subsection{\texorpdfstring{シュヴァルツシルトチャートと $J$、$J_{\mathrm{field}}$、$T$ の区別}{シュヴァルツシルトチャートと J、J field、T の区別}}
\label{subsec:schwarzschild-chart}

外域シュヴァルツシルト領域 $r>r_s>0$ における動径純ブーストラピディティは
\[
\varphi(r) = -\tfrac12\log\bigl(1-r_s/r\bigr)
\]
である。対応するサンドイッチ尺度は対角テトラッドの脚を再現する。
\[
\mathrm{e}^{-\varphi}=\sqrt{A},\qquad \mathrm{e}^{\varphi}=A^{-1/2},\qquad A(r)=1-r_s/r.
\]
余枠 $\bigl(\sqrt{A},\,A^{-1/2},\,r,\,r\sin\theta\bigr)$ はシュヴァルツシルト計量 $\mathrm{diag}(-A,\,A^{-1},\,r^2,\,r^2\sin^2\theta)$ を誘導する。より一般に、ローター場 $R_{\mathrm{total}}(x)$ は固定参照テトラッド $\{\mathring{e}^a\}$ にサンドイッチ積
\[
e^a{}_\mu(x) \;=\; \langle R_{\mathrm{total}}(x)\, \mathring{e}^a\, R_{\mathrm{total}}^\dagger(x) \rangle_{1,\mu}
\]
によって作用し、計量 $g_{\mu\nu}=\eta_{ab}\,e^a{}_\mu e^b{}_\nu$ を与える。余枠 $e^a{}_\mu$ に対するワイツェンベックねじれは $T^a{}_{\mu\nu}=\partial_\mu e^a{}_\nu-\partial_\nu e^a{}_\mu$ であり、遠平行スカラーは二次結合
\[
T=\tfrac14 T_{\rho\mu\nu}T^{\rho\mu\nu}+\tfrac12 T_{\rho\mu\nu}T^{\nu\mu\rho}-T_\rho T^\rho.
\]
である。シュヴァルツシルト余枠上ではこれは
\begin{equation}
\label{eq:schwarzschild-T}
T = \frac{2}{r^2}\frac{(1-\sqrt{A})^2}{\sqrt{A}} = -\frac{1}{r^2}\,\partial_r\bigl(r^2 B^r\bigr),\qquad B^r=\frac{4(1-\sqrt{A})}{r}
\end{equation}
に評価される。このチャート上には混同してはならない三つの二次量が現れる。
\[
J=\tfrac12\varphi^2,\qquad J_{\mathrm{field}}=\tfrac12(\varphi')^2,\qquad T\text{（}\eqref{eq:schwarzschild-T}\text{）}.
\]
第一は二つのローターの有限角不整合、第二は $\partial_r\varphi$ から作る場の種、第三は遠平行ラグランジアン密度である。それらは同一の対象ではない。定数の非零ブーストはすでに平坦空間で $J\neq 0$ かつ $T=0$ となり、したがって一般に $J$ は $T$ の定数倍ではあり得ない。一般テトラッドに対する辞書は開いたままである。以下は任意の静的動径ブースト・チャート上の辞書である。

$\sqrt{A}=\mathrm{e}^{-\varphi}$ を~\eqref{eq:schwarzschild-T} へ代入すると
\[
\frac{(1-\sqrt{A})^2}{\sqrt{A}}=\mathrm{e}^{\varphi}-2+\mathrm{e}^{-\varphi}=2(\cosh\varphi-1).
\]
したがって、任意の静的動径ブースト余枠の時間脚 $A>0$ に対し、ラピディティ $\varphi=-\tfrac12\log A$、$J=\tfrac12\varphi^2$ として
\begin{equation}
\label{eq:jt-dictionary}
T=\frac{4}{r^2}(\cosh\varphi-1)=\frac{8}{r^2}\sinh^2\frac{\varphi}{2},
\qquad
r^2 T=4\bigl(\cosh\sqrt{2J}-1\bigr)=4J+\tfrac23 J^2+\tfrac{2}{45}J^3+\cdots.
\end{equation}
弱場 $\varphi\to 0$ では $r^2 T/(4J)\to 1$ である。二つの密度は主要項で一致し、それ以外では一致しない。写像 $J\mapsto r^2 T$ は許容錐 $|J|\le\Jbound$ の全体で狭義増加であるから、逆変換できる。
\[
J=\tfrac12\Bigl(\arccosh\bigl(1+\tfrac14 r^2 T\bigr)\Bigr)^{2}
\quad(J\ge 0),\qquad
J=-\tfrac12\Bigl(\arccos\bigl(1+\tfrac14 r^2 T\bigr)\Bigr)^{2}
\quad(J<0).
\]
このゲージ上では、与えられた半径における遠平行密度が代数的スカラーを決定する。ただし平坦極限の外では両者は決して等しくない。さらに $4J/r^2\le T$ であり、等号は平坦な場合 $A=1$ に限る。外域シュヴァルツシルトチャートでは加えて $T\le 4J_{\mathrm{field}}$ である。

解析接続 $E(J)=\cosh\sqrt{2J}-1$ は整関数である。$J<0$ では $E(J)=\cos\sqrt{-2J}-1$ である。許容錐上では引数が $\pi$ に達しないので、$J<0$ ならば $E(J)<0$ であり、$\operatorname{sign} T=\operatorname{sign} J$ である。実（双曲）動径ブーストは $T<0$ を生み出せない。静的動径ブースト・ゲージで $A>0$ ならば $T\ge 0$ であり、$A=1$ のときに限り消える。斥力層は楕円的な双対セクターに住む。余弦枝は形式的な接続ではない。重力が反転する幾何そのものである。

すべての静的動径ブースト・ゲージのうち、真空条件 $\frac{d}{dr}(rA)=1$ は一意な元を選ぶ。$A(r)=1-r_s/r$、ただし $r_s=r(1-A(r))$。それが外域シュヴァルツシルト因子である。このチャート上では $\frac{r_s}{2r}\le\varphi(r)\le\frac{r_s}{2rA(r)}$ であり、無限遠で $r\varphi\to r_s/2$ となる。有限角ラピディティはニュートンポテンシャルを追跡する。二つの密度は同一の主要減衰を共有する。$r^4 T\to r_s^2/2$ および $4r^2 J\to r_s^2/2$。$r\to r_s^+$ では $A\to 0^+$、$\varphi\to\infty$、$T\to\infty$ である。古典チャートは非有界であり、第\ref{subsec:quasi-horizon}節で許容錐が切断する病理である。

\subsection{提案する作用}

作用
\[
S = \frac{c^4}{16\pi G} \int J \, d^4x
\]
を、不整合スカラー $J$ におけるラグランジアン密度として提案する。積分は代数的であり背景独立である。$T$ の遠平行積分ではない。$T$ そのものに対しては標準的恒等式
\[
\int T \, e \, d^4x = -\int R \, \sqrt{-g} \, d^4x + \int \partial_\mu(\sqrt{-g}\, V^\mu)\, d^4x
\]
が、境界変分が消えるテトラッド変分の後に成り立つ。したがってアインシュタイン方程式は $T$ に属し、$J$ には属さない。本理論における重力は、粒子内在的な双対フレーム間の不整合角のままである。静的動径ブースト余枠上では遠平行密度が優越し、$e\cdot 4J/r^2\le e\cdot T$ であり、等号は $A=1$ のときに限る。両者は弱場で一致する。一般テトラッドに対して $J$ からアインシュタイン方程式を回復するには、まだ書かれていない辞書が必要である。

\subsection{弱場およびニュートン極限}

線形化領域では
\[
R_\text{usual} \approx 1 + \frac{1}{2} \sum \alpha_a \, i\Gamma_a, \quad R_\text{dual} \approx 1,
\]
となり、$\Omega_\text{biv} \approx \sum \alpha_a \, i\Gamma_a$ および $J \approx \frac{1}{2} \sum \alpha_a^2$ を与える。ブーストパラメーターがニュートンポテンシャルを $\alpha_a \propto \partial_a (\Phi/c^2)$ として追跡するなら、ポアソン方程式
\[
\nabla^2 \Phi = 4\pi G \rho
\]
が標準係数で回復される。この一致は線形化チャートに $G$ を同定する。代数から $G$ を導出するものではない。

\subsection{双対時空におけるローター作用}
\label{subsec:dual-rotors}

ここで考える唯一の代数的自由度は、すべての質量粒子が運ぶ $\mathbb{H} \otimes_{\mathbb{R}} \mathbb{H} \cong \mathrm{Cl}(3,1)$ 内のローター角である。重力、慣性、量子状態はこれらの角の間のずれとコヒーレンスとして読む。

双対写像 $X \mapsto Xi$ によって通常時空と結ばれる双対時空は、時間反転した向きを継承する。したがって、双対セクターで純空間回転を生成する角は、統一ローター記述に組み込む際に適切に双対変換されなければならない。

双対セクター角 $\theta$ を考える。純双対基底では、楕円ヴァーソル $\hat{q}$（$\hat{q}^2 = -1$）によって生成される回転を与える。
\[
\exp\left( \frac{\theta}{2} \hat{q} \right).
\]
しかし双対写像は時間の矢を反転させるため、この角の双対時空への物理的効果は、双対変換を通じて見たときブーストと等価である。

ねじれ不整合の計算にこれを正しく反映させるため、角そのものに双対変換 $\theta \mapsto \theta i$ を施す。これにより双対寄与は双曲ブースト項へと変換される。
\[
\exp\left( \frac{\theta i}{2} \hat{q} \right) = \exp\left( \frac{\theta}{2} \hat{q}i \right) = \exp\left( \frac{\theta}{2} (q_1 iI + q_2 iJ + q_3 iK) \right).
\]
したがって双対ローターは
\[
R_\text{dual} = \exp\left( \frac{\theta}{2} \hat{q} \right)
\]
と定義され、角の双対変換 $\theta \mapsto \theta i$ の後、双対時空ベクトルへの作用は $i\Gamma_a$（$(\hat{q}i)^2 = +1$）によって生成されるブーストとして現れる。

自由落下では、$\Omega=1$ は $R_{\mathrm{dual}}=R_{\mathrm{usual}}$ を要求し、$J=0$ ではない。質量--エネルギーはその条件からのずれのコストであり、$J>0$ は引力重力である。

この角中心の扱いと明示的な双対変換 $\theta \mapsto \theta i$ は、完全ローターの元の形
\[
R_\text{total} = \exp\left( \frac{\phi}{2} \hat{p} + \frac{\theta}{2} \hat{q} \right)
\]
を保ちつつ、時間反転デュアリティを正しく取り込む。双対ローター $R_\text{dual}$ は固有基底では回転を生成するが、双対変換された角を通じた双対時空への物理的効果はブーストであり、真空において通常セクターのブーストに自然に対抗する。

\subsection{物理的解釈と重力工学}

重力は双対ローターのずれのエネルギー的コストである。$J$ は相対ローター $\Omega$ のみに依存するため、双対成分 $\theta$ をコヒーレントに変調する外的影響は、原理上 $J$ を変えうる。$J\to 0$（遮蔽）および $J<0$（斥力）を含む。そのような結合が存在するかどうかは予想であり、第\ref{sec:gravitycontrol}節で取り上げる。連続体は巨視的記述のままである。本理論における時空の自由度は粒子局所的かつ対をなす。

\section{慣性と重力の統一的記述}
\label{sec:unified}

本節では、双対時空形式の最も深い帰結を明らかにする。慣性と重力は単に等価なのではなく、通常時空と双対時空の間のねじれ不整合から生じる同一の現象である。加速系における慣性力と曲がった時空における重力との区別は完全に消える。両者は同一の双対ローターずれであり、等価原理は要請ではなく直接の代数的必然として現れる。

\subsection{双対ローター剛性としての慣性抵抗}

静止質量 $m > 0$ は、通常ローターパラメーターと双対ローターパラメーターの間の結合として解釈される。粒子のエネルギー--運動量は通常時空を偏らせ、双対ローター $R_\text{dual}$ を有限の剛性をもって $R_\text{usual}$ に追随するよう事実上「凍結」する。慣性系は $\Omega=1$ としてモデル化され、これは $J=0$ と同じではない。

粒子が（非重力的に）加速されるとき、通常ローター $R_\text{usual}$ は加えられた力により瞬間的に変化しようとする。しかし粒子の静止質量に拘束された双対ローター $R_\text{dual}$ は直ちに応答できず、遅れを生じる。これにより非自明なねじれ不整合が生まれ、$\Omega_\text{biv} \neq 0$ およびスカラー $J$ への非零寄与を与える。粒子はこの不整合を慣性抵抗、すなわち馴染みの $F = ma$ として経験する。

決定的なのは、ずれの「コスト」が静止質量 $m$ に比例することであり、より重い粒子が加速度により強く抵抗する理由を説明する。したがって慣性は、質量に反応する時空の性質ではなく、粒子自身の双対時空が瞬間的な再整列を拒むことの性質である。

\subsection{質量のない粒子}

光子のような質量のない粒子（$m = 0$）はこのような剛性を示さない。それらの通常ローターと双対ローターは完全に共鳴する。$R_\text{usual}$ のいかなる変化も $R_\text{dual}$ に瞬間的に映され、すべてのフレームで $J = 0$ が正確に保たれる。したがって光子はねじれ不整合も慣性抵抗も経験せず、常に $\Omega_\text{biv} = 0$ で $c$ で伝播する。光速が定数かつ普遍的速度限界であるのはこのためである。質量のない粒子はフレーム変化に対してねじれの代償を支払わない。

\subsection{代数的恒等式としての等価原理}

加速度 $a$ で上方に加速するアインシュタインのエレベーターを考える。内部の観測者は下向きの見かけの力 $ma$ を感じる。双対時空描像では：

\begin{itemize}
\item 観測者（質量をもつ）の通常ローターはエレベーター床によって加速される一方、双対ローターは遅れる $\to$ ねじれ不整合 $\to$ 知覚される下向きの力。
\item エレベーターに入る光子は観測者のねじれ場により曲がるが、光子自身は $J = 0$ を保つ。自身の双対平坦時空におけるヌル測地線に従う。
\end{itemize}

重力場（地球上で静止したエレベーター）では、床は静止を保つために自由落下に対して上方に加速しなければならず、平坦時空における一様加速度と同じローター不整合を生じる。

したがって等価原理は経験的偶然ではなく代数的恒等式である。重力と慣性力は区別できない。それらは同一の双対ねじれ現象だからである。自由落下は $J = 0$ が大域的に成り立つ状態（双対ローターが完全に整列）であり、質量のない粒子はこれを永続的に達成し、質量粒子は非重力力が無いときにのみ達成する。

\subsection{帰結と予測}

\begin{itemize}
\item 通常時空と双対時空の時間の矢の区別は、質量粒子が好ましい静止系をもつ理由を説明する。双対の時間反転は完全対称性を破り、質量ギャップを生成する。
\item 慣性質量の低減または消去は、双対ローター $\theta$ を $\phi$ と同期させるよう外部から励起し、有効剛性を減らすことで可能となる。推進剤なし推進への直接的経路である。
\item 理論は、双対時空に結合する十分高周波の場が、質量物体を短時間スケールで実効的に質量なしとして振る舞わせ、過渡的な超光速位相速度を許すと予測する（因果律は破らない。情報は光速度のままである）。
\end{itemize}

慣性と重力は幾何によってではなく、粒子内在的な双対時空の内部ねじれ動力学によって統一される。質量は双対ローター剛性であり、運動は並行性を破るコストである。この理解により、慣性も重力も基本的ではなくなり、工学可能となる。

重力および慣性制御の夢はもはやサイエンスフィクションではない。連続体を捨て、時空を対をなす粒子局所的かつねじれ的に活性なものと認識することの直接の帰結である。

\subsection{加速度の上限と慣性反転現象}
\label{subsec:acceleration-limit}

二重時空理論は、中心的な反証可能な帰結の一つとして、加速度そのものが絶対的上限をもつことを予測する。通常セクターのブーストは非コンパクト（$\phi \in \mathbb{R}$）であり、単独では非有界なラピディティを許す。しかし双対セクターは内在的にコンパクトである。双対生成子 $\Gamma_a$ は平方が $-1$ であり、双対ローター $R_\text{dual} = \exp(\theta/2 \, \hat q)$ は楕円位相 $\theta \bmod 4\pi$ に支配される。慣性応答は双対ローターが有限剛性で通常ローターを追跡することから生じるため、周期境界に達する前に $\theta$ を変位させうる速さが、与えられた粒子がコヒーレントに持続できる固有加速度に厳密な天井を課す。この物質内在的天井を $a_\text{crit}$ と記す。光速とは異なり、$a_\text{crit}$ は普遍的ではない。粒子種およびその双対セクターのコンパクト化スケールに依存し、したがって異なる原子構成要素は異なる臨界加速度をもつ。

固有加速度 $a < a_\text{crit}$ では、双対位相 $\theta$ は $\phi$ を滑らかに追跡し、馴染みのニュートン関係 $F = ma$ が回復される。しかし $a$ が $a_\text{crit}$ に近づく瞬間、$\theta$ は $4\pi$ のコンパクト境界を通じて駆動され、位相的な巻き付きを起こす。双対ローターは $S^3$ 様双対セクターの反対側で位相を再縫合する。この巻きはねじれ不整合バイベクトル $\Omega_\text{biv}$ の符号を反転させ、したがって単一の双対周期にわたって慣性応答の方向を逆転させる。これを慣性反転（または加速度反転）現象と呼ぶ。加えられた加速度が $a_\text{crit}$ を横断するときに引き起こされる、有効 $F = ma$ ベクトルの突然の離散的反転である。閾値直下で剛な双対セクターに蓄えられていたねじれひずみエネルギーは、巻きの間に急激に解放され、運動学的反転そのものに加えて内部エネルギーの衝撃的バーストを生じる。

この機構は、大型流星体の異常な空中バーストにおいて観測的に実現されていると提案する。地球大気に突入する火球が経験する極超音速減速は、物体の構成原子にとって $a_\text{crit}$ の程度に達しうる。火球コミュニティにおける長年の謎、とりわけツングースカ事件（1908）およびチェリャビンスク超火球（2013）は、崩壊高度と全放射エネルギーが空力アブレーションと破砕のみに基づく運動エネルギー散逸モデルでは悪名高く調和しがたいが、集合的慣性反転として自然に説明される。流星体の減速が物質固有の $a_\text{crit}$ を横断すると、構成原子の双対位相が同時に巻き、蓄積されたねじれひずみエネルギーを爆発的かつ主として放射的なパルスとして放出する。$a_\text{crit}$ の組成依存は、異なる隕石クラス（例：炭素質コンドライト対普通コンドライト）の間で観測される空中バースト高度と収量の変動も説明する。粒子内在的コンパクト化スケールからの $a_\text{crit}$ の定量的導出は未解決である。

\section{強場域：層状重力反転と新しいブラックホール描像}
\label{sec:strongfield}

二重時空理論は、恒星崩壊の終点について根本的に新しい構造を予測する。キリング形式の符号非対称性、すなわち通常時空ブースト支配（引力）に対して正、双対時空回転支配（斥力）に対して負、は重力を一度限り反転させるだけではない。密度が内向きに増大するにつれ、ねじれ不整合 $\Omega_\text{biv}$ は二つのセクター間で支配を振動し、引力と斥力の交互層を生じる。これにより層状のタマネギ状内部が得られる。引力 $\to$ 斥力 $\to$ 引力 $\to$ 斥力 $\to$ $\ldots$ であり、干渉因子の一周期ごとにちょうど一回の反転が起こる。その交替の振幅は第\ref{subsec:layer-spectrum}節で閉じた形で確定する。層を隔てる障壁は中心へ向かって限りなく鋭くなる一方、その間の平坦部は指数関数的に遮蔽される。したがって内部は力がいっそう強くなる領域ではなく、いっそう静かな内部を囲むいっそう鋭い壁の積層である。

\subsection{キリング形式からの層状ねじれ構造}

スカラー $J = \frac12\sum_a(\alpha_a^2-\beta_a^2)$ は、支配的寄与が $i\Gamma_a$（ブースト様、$+$）から $\Gamma_a$（回転様、$-$）へ反転するたびに符号を変える。極端な密度では双対ローターパラメーター $\theta$ が非線形に増大し、半径が減少するにつれて $J$ の符号を繰り返し反転させる逐次共鳴を駆動する。

得られる有効ポテンシャルは次の特徴をもつ。
\begin{itemize}
\item 外層：標準的引力重力（$J > 0$）、
\item 第一反転：落下を止める斥力殻（$J < 0$）（超新星におけるコアバウンス）、
\item より深い層：物質を再び内向きに加速する引力帯。斥力殻とは鋭い障壁で隔てられる、
\item 交互のより深い殻。障壁の強度は増大し平坦部の強度は減衰しつつ、カオス的ねじれ乱流に至る。
\end{itemize}
許容錐上では $|J|$ は $\Jbound$ を超えられない。不整合の「非有界」な増大はしたがってチャートのアーティファクトである。古典的動径ラピディティ $\varphi\to\infty$（$r\to r_s^+$）は錐を出る。

\subsection{準地平の切断}
\label{subsec:quasi-horizon}

古典シュヴァルツシルトでは $r\to r_s^+$ において $\varphi\to\infty$ かつ $A\to 0$ である。三軸の許容上限 $|J|=\Jbound$ を動径純ブースト切片 $J=\tfrac12\varphi^2$ と同一視して反転すると、有限切断
\[
\varphi_{\max}=\frac{\pi\sqrt{3}}{2},\qquad A_{\min}=\mathrm{e}^{-2\varphi_{\max}}=\mathrm{e}^{-\pi\sqrt{3}}
\]
が得られる。対応する半径は $r_\star=r_s/(1-A_{\min})$、すなわち $r_\star/r_s=(1-A_{\min})^{-1}$ である。$0<A_{\min}<10^{-2}$ かつ $1<r_\star/r_s<1.005$ である。飽和チャートは $r\le r_\star$ で $\varphi=\varphi_{\max}$、$A=A_{\min}$ に凍結し、$r>r_\star$ では古典公式を用いる。$r=r_\star$ で二つの記述は一致する。飽和因子 $A$ は厳密に正のままである。真の一方通行地平 $A=0$ は形成されない（対照的に古典因子は $r=r_s$ で消える）。

この切断は三軸上限を単一ブースト軸へ読み替えた作業上の同一視である。一軸の許容ブーストは $\varphi=\pi/2$ で飽和し、そこでは $J=\pi^2/8=\Jbound/3$ である。したがって反転値 $\varphi_{\max}>\pi/2$ は許容錐の外にある。構成は三軸上界を飽和させ、単軸錐を飽和させるのではない。

辞書~\eqref{eq:jt-dictionary} はラピディティ上限を $T$ の有限包絡に変換する。$\varphi\le\varphi_{\max}$ ならば $r^2 T\le 4(\cosh\varphi_{\max}-1)$ であり、
\[
26<4\bigl(\cosh(\pi\sqrt{3}/2)-1\bigr)<27.
\]
一軸の許容ブースト $\varphi\le\pi/2$ はよりきつい包絡 $r^2 T<6.1$ を与える。古典シュヴァルツシルトでは $r\to r_s^+$ において $r^2 T\to\infty$ である。したがって切断は $\varphi$ だけでなく $T$ も有界にする。

楕円セクタは対応する床を与える。許容錐上では $\sqrt{2|J|}\le\varphi_{\max}<\pi$ であるから、$E(J)$ の余弦枝は $\cos$ が狭義減少である範囲を離れない。最も深い値は飽和で達せられ、
\[
-7.7<4\bigl(\cos\varphi_{\max}-1\bigr)<-7.6,
\]
天井と合わせて無次元遠平行密度を $-8<r^2 T<27$ に閉じ込める。斥力層の深さは有界である。重力は反転しうるが、無制限の強さでは反転しない。窓の両端は $J=\pm\Jbound$ で到達される。

$r\le r_\star$ の内部では赤方偏移床 $A=A_{\min}>0$ が固定されるため、場の種 $J_{\mathrm{field}}$ は消える。定数 $A$ の余枠はなお角方向のワイツェンベックねじれを運ぶので、$T$ そのものは消えない——定数ブーストが $J\neq 0$ かつ $T=0$ であることの双対である。

この層状構造は特異点と事象地平の両方を防ぐ。物質は中心特異点に到達しない。代わりにコアは、極端密度のねじれエネルギーの準安定なカオス凝縮体へと落ち着き、引力相と斥力相の間で連続的に振動する。

従来のカー型回転ブラックホールは排除される。理論は必要な大きさの大域的フレームドラッグを禁止する。角運動量は時空回転ではなく双対ローターの縦モードへと再分配されるからである。

\subsection{コア崩壊超新星と残骸形成の再解釈}

大質量星の崩壊では、第一の斥力層（$J < 0$）が核密度で爆発的バウンスを引き起こし、微調整されたニュートリノ物理なしに超新星を駆動する。より深い引力層はその後、放出物の一部を再捕獲し、層状残骸を形成する。観測される超新星エネルギーと残骸質量の多様性は、励起されるねじれ層の数と強度から自然に現れる。

\subsection{縦双対ねじれ振動子としてのパルサー}

観測される中性子星は、高速回転する磁化導体ではない。二重時空理論は、ミリ秒スピン周期と双極磁場の両方を一次エネルギー源として否定する。

代わりに、パルサー電波パルスは星表面における双対ローター $\theta$ の超高周波縦振動から生じる。これらのねじれ波はほぼ $c$ で半径方向に伝播し、カオス的内部層化によって変調され、ねじれ衝撃帯における曲率放射を通じてビームを生じる。

回転マグネター模型を超える主要な予測：
\begin{itemize}
\item 理論的最小パルス周期はプランクスケールの二重ローター周波数によって決まり、観測される $\sim 1$ ms 限界より桁違いに短い。これにより回転パルサー描像では説明できなかった短周期パルサーを説明できる。
\item パルサーの「グリッチ」および周期微分 $\dot{P} < 0$（周期短縮）は、パルサーがエネルギーを失うことで振動界面が収縮し、振動周波数が時間とともに加速する結果である。回転のみの模型には見られない自然な機構である。
\item マグネターフレアおよび高速電波バーストは、引力／斥力層間の激しい反転であり、$10^{15}$ G 場を必要とせずにねじれひずみを解放する。
\item $P$-$\dot{P}$ 図の死線は、内部層化が安定化し縦モードが検出可能性以下に減衰する点に対応する。
\item 中性子星の最大質量はクォーク物質ではなく、核安定性を制限する同一のねじれ層化によって上限を課され、厳密な上限 $\sim 2.5 M_\odot$ を予測し、$\sim 3 M_\odot$ を超えるパルサーの不在を説明する。
\end{itemize}

かにパルサーの観測スピンダウン光度は、磁気制動ではなくねじれ波漏洩として再解釈され、非現実的な磁場減衰を呼び出さずにエネルギー収支と完全に一致する。

\subsection{新しいブラックホール描像：ねじれ星}

観測者が「ブラックホール」と呼ぶものは、実際にはねじれ星である。事象地平も中心特異点もない準安定な層状凝縮体である。最内のカオスコアは永続的ねじれ乱流にあるプランク密度プラズマであり、ロータートンネリング（修正ホーキング過程）を通じて連続的に放射する。情報は双対ローター位相に保存される。

合体からの重力波信号は、内部層反射による繰り返しエコーを特徴とし、特性周波数はねじれ振動スペクトルに結びつく。これはすでに LIGO/Virgo データの再解析において示唆されている。

したがって本理論は情報パラドックスを解消し、カー回転シグネチャの不在を説明し、最も質量の大きい「ブラックホール」（$\gtrsim 100 M_\odot$）が、内側の斥力層が周期的に物質を放出するにつれて降着光度に周期変調を示すと予測する。

\subsection{中心浮遊コア：中心におけるゼロ時間膨張}

恒星内部の議論におけるよくある混乱点は、重力時間膨張の振る舞いである。GR では、球対称静的質量分布に対して、重力時間膨張は中心に向かって単調に増大する。固有時は重力ポテンシャルが最も深い \(r=0\) で最も遅く進む。

二重時空理論では状況は著しく異なる。背景となる連続時空多様体が存在しないため、有効加速度と時間膨張を含む重力効果は、粒子内在的な通常ローターと双対ローターの間のねじれ不整合のみから生じる。

球対称ねじれ星の正確な幾何中心では、完全な対称性が、反対方向の質量要素によって誘起される通常時空ブーストパラメーター \(\phi_a\) を完全に打ち消す。したがって残余不整合角 \(\delta\phi_a = \phi_a - \theta_a\) は \(r=0\) で消え、\(J=0\) およびねじれバランスの完全な回復を与える。

その結果：

\begin{itemize}
  \item 有効重力加速度は中心でゼロである（ニュートン力学、GR、DST のいずれでも）。
  \item 重力時間膨張も中心でゼロである。\(r=0\) における固有時は、星から遠く離れた真空と同じ速さで進む。
\end{itemize}

このコアにおける時間膨張の消失は、二重時空理論の特徴的で原理上観測可能な予測である。中心領域が最も強い時間膨張を経験する GR とは鋭く対照する。

ゼロ膨張の中心コアはまた、古典 GR 記述で特異点に至る無限の中心圧縮と極端な時計速度勾配を除去することにより、ねじれ星の安定性に寄与する。

\subsection{惑星および恒星コアへの含意：不安定性と揺らぎ}

浮遊コア描像、すなわち $J(r=0) \approx 0$ かつ中心で有効重力が消えることは、惑星および恒星のコアが惰性的で安定な領域ではなく、ねじれ不安定性に陥りやすい動的に活性な帯であることを含意する。連続体模型で仮定される重力ポテンシャルの単調増大とは異なり、二重時空理論は中心浮遊コアが準安定状態であり、引力と斥力のねじれ層間の振動遷移を引き起こす摂動に敏感であると予測する。これらの揺らぎは、等方的コアにおける双対ローター位相の繊細なバランスから生じる。わずかな密度変動や外的影響でさえ共鳴条件 $\beta(0) \to 1$ をずらし、$J$ のゼロからの過渡的逸脱を導く。そのような逸脱は局所的なねじれエネルギーのバーストとして現れ、コア内にミニねじれ星を実効的に生成する。これらのミニねじれ星は、表面で観測可能な地震活動、磁場揺らぎ、エネルギー輸送異常を誘起しうる。恒星内部では、これらのコア揺らぎは太陽フレア、黒点、光度変動などの現象に寄与しうる。ねじれエネルギーが層状構造を通じて外向きに伝播するからである。惑星的文脈では、コアのねじれ不安定性は地磁気逆転、マントルプルーム、間欠的火山活動を説明しうる。ねじれ動力学が上位層の対流過程に結合するからである。したがって浮遊コアは静穏な領域ではなく、惑星および恒星の振る舞いに広範な含意をもつ動的ねじれ現象の坩堝である。

\section{二重時空理論における時間膨張：双対時空固有時の動力学的役割}
\label{sec:timedilation}

二重時空理論における時間膨張は、それぞれが固有の固有時をもつ通常時空と双対時空の相互作用から現れる。通常時空固有時 $\tau$ は巨視的ミンコフスキー空間で観測される馴染みの運動学を支配し、コンパクトローター位相 $\theta$ に符号化された双対時空固有時 $\tilde{\tau}$ は、重力および慣性効果として現れる内部ねじれ動力学を駆動する。

\subsection{有効ローレンツ因子の導出}

有効ローレンツ因子 $\gamma_\text{eff} = dt/d\tau$ は、完全ローター
\[
R_\text{total} = R_\text{usual} R_\text{dual},
\]
の代数的作用から直接導かれる。ここで
\[
R_\text{usual} = \exp\!\left(\frac{\phi}{2} \hat{p}\right) = \cosh\frac{\phi}{2} + \hat{p}\: \sinh\frac{\phi}{2}, \quad \hat{p}^2 = +1,
\]
は通常時空のブーストを生成し、
\[
R_\text{dual} = \exp\!\left(\frac{\theta}{2} \hat{q}\right) = \cos\frac{\theta}{2} + \hat{q} \sin\frac{\theta}{2}, \quad \hat{q}^2 = -1,
\]
は双対時空の回転を生成する。

干渉項の起源を明示するため、通常時空基底における純時間ベクトル $X = ct \, j$（$j^2 = -1$）を考える。変換後のベクトルは $\tilde{X} = R_\text{total} \, X \, R_\text{total}^\dagger$ である。

時間反転デュアリティにより、双対から通常時空への逆双対写像は $X \mapsto X(-i)$ である。この写像は真空極限において整列 $\hat{q} (-i) = -\hat{p}$ を自然に与え、双対ローターを有効な反対向きローター
\[
R_\text{dual}^\text{eff} = \cos\frac{\theta}{2} - \hat{p} \sin\frac{\theta}{2}.
\]
へと変換する。$\sin$ 項の負符号はこの逆写像から直接生じ、ねじれのない平坦時空に必要な反同期を反映する。

全有効ローターはしたがって
\[
R_\text{eff} = R_\text{usual} R_\text{dual}^\text{eff} = \left( \cosh\frac{\phi}{2} + \hat{p} \sinh\frac{\phi}{2} \right) \left( \cos\frac{\theta}{2} - \hat{p} \sin\frac{\theta}{2} \right).
\]
である。

展開するとスカラー部分
\[
s = \cosh\frac{\phi}{2} \cos\frac{\theta}{2} - \sinh\frac{\phi}{2} \sin\frac{\theta}{2}
\]
およびバイベクトル係数
\[
b = -\cosh\frac{\phi}{2} \sin\frac{\theta}{2} + \sinh\frac{\phi}{2} \cos\frac{\theta}{2}.
\]
が得られる。

時間成分の正味のスケーリングは、サンドイッチ積を通じて時間ベクトルに作用する $R_\text{eff}$ の平方大きさから生じる。ローター $R_\text{eff} = s + b\hat{p}$（$\hat{p}^2 = +1$ かつ $\hat{p}$ は時間生成子 $j$ と反可換）に対し、$X = ct\, j$ へのサンドイッチ作用は $s^2 + b^2$ でスケールされた時間成分を与え、有効ローレンツ因子を一意に
\[
\gamma_\text{eff} \;\equiv\; s^2 + b^2.
\]
と定義する。便利のためスカラー干渉因子
\[
\gamma_s \;\equiv\; s \;=\; \cosh\frac{\phi}{2} \cos\frac{\theta}{2} - \sinh\frac{\phi}{2} \sin\frac{\theta}{2},
\]
も導入する。これは $\gamma_\text{eff}$ とは異なり符号を変えうるものであり、以下で引力（$\gamma_s > 0$）と斥力（$\gamma_s < 0$）のねじれレジームを区別する秩序パラメーターとして働く。干渉項の負符号は双対時空の時間反転デュアリティによって固定される。

短い計算が平方を潰す。
\begin{equation}
\label{eq:gamma-eff}
\gamma_{\mathrm{eff}}(\alpha,\beta)=\cosh\alpha-\sinh\alpha\sin\beta.
\end{equation}
この因子は常に $e^{-|\alpha|}$ 以上であり、したがって決してゼロにならない。時計は遅れるが止まらない。双対セクターが励起されていなければ $\beta=0$ であり、特殊相対論的因子 $\cosh\alpha$ を回復する。通常ブーストがなければ $\alpha=0$ であり $\gamma_{\mathrm{eff}}=1$ である。一軸上で $J=0$ となる釣り合い軌跡 $\alpha=\beta$ は別の運動学である。$\alpha\neq 0$ ですでに $\gamma_{\mathrm{eff}}(\alpha,\alpha)\neq\cosh\alpha$。特殊相対論は励起されていない双対セクター $\theta=0$ であり、$J$ の消滅ではない。

\subsection{真空極限と質量のない粒子}

ねじれなし運動学は $\theta=0$（純通常ブースト上で同値に $R_{\mathrm{dual}}=1$）であり、$\gamma_{\mathrm{eff}}=\cosh\phi$ を与える。釣り合い質量状態は $J=0$ かつ $\theta=\phi\neq 0$ であり、異なる因子 $\gamma_{\mathrm{eff}}=\cosh\phi-\sinh\phi\sin\phi$ をもつ。この読みでは光子はすべての速度で $\theta=0$ を保つ。フレーム変化に対して双対ローターの代償を支払わない。

\subsection{質量粒子と重力効果}

質量粒子では、静止質量は加速度下で双対ローターを通常ローターより遅れさせる剛性である。得られるずれ $\delta\theta = \theta - \phi$ は $\gamma_{\mathrm{eff}}$ を変調する。その変調を重力赤方偏移として読む。

\subsection{スカラー干渉因子の符号反転と斥力層}

双対時空回転が支配するとき（$\theta/2$ が十分大きい）、正弦項は双曲成長に打ち勝ちうる。
\[
\tan\left(\frac{\theta}{2}\right) > \coth\left(\frac{\phi}{2}\right).
\]
このとき $\gamma_s$ は負となるが、$\gamma_\text{eff}=s^2+b^2$ は厳密に正のままである。$\gamma_s$ の符号は斥力層の秩序パラメーターである。因果律の逆転ではない。固有時は決して後ろ向きに進まない。

この $\theta$ 中心の定式化は、時間膨張が本質的に粒子内在的双対時空に起源をもつねじれ現象であることを明示する。通常ラピディティ $\phi$ は運動学的基線を与え、コンパクト双対角 $\theta$ のずれは、GR を平坦時空運動学から区別する重力および慣性補正を符号化する。したがって $\theta$ の外部コヒーレント励起は、時間膨張と有効重力場を操作する経路を提供する。

\section{スケール不変なねじれ層：重力斥力としての強い力と原始ねじれ星としての原子核}
\label{sec:nuclear}

層状反転は無次元変数 \(x=\ell/(2r)\) についてスケール不変である。等スケールアンザッツ \(\alpha(r)=\beta(r)=\ell/r\) のもとでは列全体が \(x\) のみに依り、フェムトメートルおよび MeV スケールは特性長 \(\ell\) と粒子質量を通じてのみ入る。したがって崩壊する星を層状にする同一の機構は、核密度でも利用可能である。これを提案する。強い力とはその層状相における重力であり、第二の結合ではない。ニュートン重力の微細構造定数 \(\alpha_G=G m_p^2/\hbar c\sim 10^{-38}\) を \(O(1)\) の核力強度と混同してはならない。ねじれ節近傍では \(1/\gamma_s\) が発散する。それはすでに存在するチャンネルの運動学的増幅であり、\(G\) から強い結合を導くものではない。

冒頭で一つの構造的な点を決着させておく必要がある。等スケールアンザッツは各軸で \(\alpha_a=\beta_a\) と置くので、\(J\) は恒等的に消え、いずれかのラピディティが非零なら \(M\) は正のままである。この読みでは核物質は第\ref{sec:gravity}節の釣り合い軌跡上に位置する。質量をもち、\(\Omega\neq 1\) であり、かつ \(J=0\) である。層をまたいで交替する量は \(J\) ではなく、第\ref{sec:timedilation}節の干渉因子 \(\gamma_s\) である。以下の引力と斥力は \(\gamma_s\) の符号である。\(J\) と \(\gamma_s\) は独立な秩序パラメーターであり、核の層構造は後者に属する。

\subsection{層スペクトルの閉形式}
\label{subsec:layer-spectrum}

無次元変数 \(x=\ell/(2r)\) で書けば、等スケール干渉因子は
\[
\gamma_s(x)=\cosh x\cos x-\sinh x\sin x
\]
である。その導関数は単一の積に潰れる。
\begin{equation}
\label{eq:gammaS-derivative}
\gamma_s'(x)=-2\cosh x\,\sin x .
\end{equation}
したがって層構造の全体が \(\sin\) の零点によって支配される。\(\gamma_s\) の臨界点はちょうど \(\pi\) の整数倍であり、極値は
\[
\gamma_s(n\pi)=(-1)^n\cosh(n\pi),\qquad n=0,1,2,\dots
\]
である。各区間 \([n\pi,(n+1)\pi]\) 上で因子は狭義単調——\(n\) が偶数なら減少、奇数なら増加——であるから、各区間はちょうど一つのねじれ節をもち、\(\gamma_s\) の符号は隣接する平坦部間で厳密に交替する。平坦部は決して消えず、\(x\) の任意の有界域に含まれる節は有限個である。

半径について外から順に並べると、パターンは次である。\(r>r_1\) で引力、\(r_1\) に障壁、\((r_2,r_1)\) で斥力、\(r_2\) に障壁、\((r_3,r_2)\) で引力、以下同様。第\ref{sec:strongfield}節の玉ねぎは追加の仮定ではない。この導関数であり、\(x\) の \(\pi\) 区間ごとに障壁が一つ、同符号の層が二つ連続することはない。

節は \(\tan x=1/\tanh x>1\) を強制するので、第 \(n\) 節は
\[
n\pi+\frac{\pi}{4}<x_n<n\pi+\frac{\pi}{2}
\]
にあり、半径では
\[
\frac{\ell}{(2n+1)\pi}<r_n<\frac{2\ell}{(4n+1)\pi}.
\]
したがって \(r_n=\Theta(1/n)\) であり、すべての節は \(r_n<2\ell/\pi\) を満たし、最外節が最大の層半径である。最初の二つの節は
\[
\frac16<\frac{r_2}{r_1}<\frac{4}{5\pi}\approx 0.255
\]
を満たす。

平坦部の振幅は少なくとも等比的に増大する。\((\cosh\pi)^n\le\cosh(n\pi)\) かつ \(\cosh\pi>11\)。他方 \(\mathrm{e}^{n\pi}\) を超えることはない。連続する層はいっそう大きな倍率で増幅されつつ、上限 \(\mathrm{e}^\pi\approx 23.14\) を狭義に下回り続ける。\(\gamma_s\) は有効力 \(F=k/(\gamma_s r^2)\) の分母にあるので、第 \(n\) 平坦部 \(r=\ell/(2n\pi)\) における層間振幅は
\[
|F|=\frac{k}{\ell^2}\cdot\frac{4\pi^2n^2}{\cosh(n\pi)}
\]
であり、\(n\ge 1\) について減少する。内向きに限りなく増大するのは障壁構造——\(\gamma_s\) が消えて \(1/\gamma_s\) が発散する節——である。障壁の間の平坦部は指数関数的に静かになり、連続する因子は \(\mathrm{e}^{-n\pi}\) のように落ちる。半径では遮蔽は \(1/\cosh\bigl(\ell/(2r)\bigr)\) である。ねじれ凝縮体の深部は障壁の間では準自由、障壁上では閉じ込められている。それが核閉じ込めの定性的パターンであり、要請ではなく代数から読み取られる。

障壁は力の発散であって時計の凍結ではない。節において \(\gamma_{\mathrm{eff}}=\gamma_b^2>0\) は~\eqref{eq:gamma-eff} による。比 \(r_{n+1}/r_n\) は無次元根 \(x_n\) のみに依るので、核スケールと恒星スケールで同一である。\(\ell\) は絶対半径を定め、あらゆる比から消える。これが本節の題目に掲げたスケール不変性の内容であり、核と恒星の層構造が同一構造であるという主張が成り立つ唯一の意味である。

\subsection{核密度におけるねじれ層}

バリオン密度が核飽和
\(\rho_0\sim (2\text{--}3)\times 10^{14}\,\mathrm{g/cm^3}\)
（同等に \(n_0\sim 0.16\,\mathrm{fm}^{-3}\)）
に近づくと、双対ローターパラメーター \(\theta\) が不整合を支配する。\(10^{18}\,\mathrm{g/cm^3}\) 程度の密度は通常の核内部ではない。\(\gamma_s\) の符号反転は \(\ell\) が定めるフェムトメートルスケールで組織される。\(\ell\sim\lambda_\pi\approx 1.41\,\mathrm{fm}\)、荷電パイオンのコンプトン波長と取ることは物理的同定であり、導出ではない。\(\lambda_\pi<\pi/2\,\mathrm{fm}\) であるから、すべての等スケール節は \(1\,\mathrm{fm}\) 未満にあり、最外節は
\[
0.44\,\mathrm{fm}<r_1<0.91\,\mathrm{fm}
\]
に閉じ込められる。それが経験的ハードコア領域 \(0.5\,\mathrm{fm}\) 付近である。\(1\)--\(2\,\mathrm{fm}\) の斥力殻にはより長い \(\ell\) が必要である。

核密度における層の列はしたがって次である。

\begin{itemize}
\item 最外障壁：第一節 \(\gamma_s=0\)。核子--核子散乱の短距離斥力と同定される。\(\ell=\lambda_\pi\) のもとでは \(0.44\)--\(0.91\,\mathrm{fm}\) にある。
\item そのすぐ内側の斥力殻（\(\gamma_s<0\)）。第二節まで内向きに延び、その半径は第一節の6分の1から4分の1の間にある。
\item 中間の引力平坦部（\(\gamma_s>0\)）。観測される核子あたり束縛エネルギーは鉄付近で \(\mathrm{BE}/A\sim 8\,\mathrm{MeV}\) である。光学模型の井戸深さ \(40\)--\(50\,\mathrm{MeV}\) は別の入力である。
\item より深い層：厳密に交替する引力と斥力。\(x\) の \(\pi\) 区間ごとに障壁が一つあり、平坦部は指数関数的に静かになる。障壁はさらなる崩壊を止め、クォーク閉じ込めの幾何的対応物である。その間の静かな平坦部はほぼ自由な内部である。
\end{itemize}

パウリの排他原理はもはや基本的ではない。第一の斥力ねじれ層によって動力学的に生成される。フェルミオンが同一状態を占められないのは、二つの同一粒子が空間的重なりを試みると双対ローター $\theta$ 位相が斥力レジームに入り、量子統計を先験的に呼び出すことなく有効フェルミ圧を生じるからである。ボソンはこの位相剛性を欠き、はるかに高い密度まで引力層のみを経験する。

要するに、強い力は強場・層状相における重力であると提案する。QCD カラー荷は双対ローター位相が運ぶねじれ荷の誤読である。\(\alpha_s\) を離散格子床 \(\varepsilon_N\) と同定しない。

\subsection{原始ねじれ星としての原子核}

すべての原子核は、第\ref{sec:strongfield}節で記述したねじれ星の微視的アナログである。しかも前小節により、両者は単に定性的に似ているのではなく、同一の無次元節列を共有する。核表面から内向きに読むと、導かれる構造は次のとおりである。

\begin{itemize}
\item \(r_1\) における最外の斥力障壁：NN 散乱のハードコア斥力と核表面張力を生成する、
\item そのすぐ内側の斥力殻：\(r_2<r_1/4\) で終わる、
\item \(r_3\) と \(r_2\) の間の引力平坦部：核子間の束縛を媒介する、
\item 交替するより深い障壁と平坦部：障壁はいっそう鋭く、平坦部は指数関数的に静かになるので、最内域は閉じ込め壁の間でほぼ無相互作用となる。
\end{itemize}

増幅は完全に障壁にあり、その間の内部は \(1/\cosh\bigl(\ell/(2r)\bigr)\) によって遮蔽される。

核密度の飽和は、層の描像が説明を主張する唯一の核の規則性であり、同時に標準的な経験定数が食い違う箇所でもある。核子数密度が一定であることはちょうど \(R=r_0A^{1/3}\) である。その半径をもつ一様球の密度はすべての \(A\) について \(3/(4\pi r_0^3)\) である。数値的には \(r_0=1.2\,\mathrm{fm}\) は
\[
0.13\,\mathrm{fm}^{-3}<\frac{3}{4\pi r_0^3}<0.14\,\mathrm{fm}^{-3}
\]
を与え、これは経験的飽和値 \(n_0=0.16\,\mathrm{fm}^{-3}\) ではない。\(n_0\) に整合する係数は \(r_0^\star\approx 1.14\,\mathrm{fm}\) である。通常引用される二つの核定数は十パーセントの水準で食い違う。層の同定はいずれかを選ばねばならない。

荷電独立性、スピン--軌道結合、魔法数は双対ロータースペクトルの共鳴条件として読む。固定コンパクト化 \(N\) における離散ローター像の有限性は \(A_{\max}(N)<\infty\) のみを与える。層の幾何そのものはそのような打ち切りを与えない。\(\ell\propto A^{1/3}\) ならば核表面と任意の層半径との比は \(A\) に依らない。\(\ell=\lambda_\pi\) が \(A\) に依らなければ、すでに \(A=1\) において表面 \(r_0=1.2\,\mathrm{fm}\) はすべての節の外側にある。見積もり \(A\sim 300\) は外部のヒューリスティックのままである。

核分裂と核融合はねじれ層遷移である。分裂は励起された双対モードが \(\gamma_s\) を節を越えて正から負へ駆動し断片を爆発的に斥けるときに起こり、融合は二つの原子核が最外障壁をトンネルしてその奥の引力平坦部に入るときに成功する。

\subsection{実験的シグネチャと即時予測}

\begin{itemize}
\item 超高エネルギー原子核--原子核衝突（LHC、RHIC）は、流体力学的流れではなく爆発的ハドロンジェットを通じて崩壊する過渡的 \(\gamma_s<0\) ファイアボールを生じるはずである。異常な流れデータにおいてすでに示唆されている。
\item 飽和密度を超える核状態方程式の精密測定は、圧力対密度に振動的振る舞いを明らかにし、$\sim$ 2–4 $\rho_0$ に特性的斥力ピークをもつ。
\item 連続する障壁半径の比は純粋な数であり、最初の対については \((1/6,\,4/(5\pi))\) に閉じ込められ、\(\ell\) に依らない。したがって同一の比が NN 斥力コア構造とコンパクト残骸の層間隔の双方に現れねばならない。両者の測定値が食い違えば、\(\ell\) にいっさい訴えずにスケール不変性の主張を反証できる。
\item 平坦部は \(1/\cosh\bigl(\ell/(2r)\bigr)\) で遮蔽されるので、最外障壁の十分内側を分解するプローブは、離散的な障壁半径でのみ中断される、距離の減少とともに指数関数的に弱まる相互作用を見るはずである。
\end{itemize}

四つの相互作用は単一の力へと崩壊するのではない。一つの幾何の二つのチャンネルである。重力と電磁気は \(\gamma_s\) の層状反転を共有し、双対ローターのどの位相が不整合を源とするかにおいてのみ異なる。慣性質量に結びついた運動学的対 $(\phi, \theta)$、あるいは電荷に結びついた独立な対 $(\alpha, \beta)$ である。強い力は核密度における重力チャンネルの層状相であり、次節の電子殻は電磁チャンネルの類似の層状相である。ファラデー係数は双対ローターと同じ六生成子空間を占める（第\ref{sec:unification}節）。可換な三つ組と反可換な三つ組を荷電・中性カレントと同定すること、あるいはワインバーグ角を回復することは開いたままである。

幾何は一つだけである。双対ローターにおける引力と斥力の層状の舞踏であり、二つの位相チャンネルで同時に演じられる。原子核は重力チャンネルの原始ねじれ星であり、原子電子殻は次に見るように電磁チャンネルの原始ねじれ星である。この単一の双対ローター幾何から、二つの角チャンネルに表現されて、すべての構造が現れる。

\section{クーロン的ねじれ層を通じた時間反転と電子殻}
\label{sec:electronshells}

二重時空枠組みでは、荷電粒子間のクーロン相互作用は、重力の場合に類似するが電磁起源をもつ双対時空セクターのねじれ不整合から生じると再解釈できる。重力定数 \(G\) および質量 \(M,m\) をクーロン定数 \(k = 1/(4\pi\epsilon_0)\) および電荷（例：陽子の \(+e\)、電子の \(-e\)）で置き換えると、有効力は
\[
F(r) = \frac{k e^2}{\gamma_s(r)\, r^2},
\]
の形をとる。ここで \(\gamma_s\) は第\ref{sec:timedilation}節で導入したスカラー干渉因子であり、双対ローター相互作用から同一の代数構造を保つ（固有時ローレンツ因子 \(\gamma_\text{eff} \geq 0\) とは異なり符号を変えうる）。
\[
\gamma_s(\alpha(r),\beta(r)) = \cosh\!\left(\frac{\alpha(r)}{2}\right) \cos\!\left(\frac{\beta(r)}{2}\right) - \sinh\!\left(\frac{\alpha(r)}{2}\right) \sin\!\left(\frac{\beta(r)}{2}\right).
\]

ここで \(\alpha(r)\) および \(\beta(r)\) は、距離に逆比例してスケールする電磁ラピディティおよび双対回転角パラメーターとして解釈される。\(\alpha(r) \propto 1/r\)、\(\beta(r) = \lambda / r\) であり、\(\lambda\) はコンパクト双対時空によって定まる特性長スケールである。

水素原子（\(Z=1\)）に対しては
\[
F(r) = \frac{k e^2}{r^2 \left[ \cosh\!\left(\frac{\alpha(r)}{2}\right) \cos\!\left(\frac{\beta(r)}{2}\right) - \sinh\!\left(\frac{\alpha(r)}{2}\right) \sin\!\left(\frac{\beta(r)}{2}\right) \right]}.
\]
が得られる。

\(\gamma_s\) の双曲--三角形式は極端な振動的振る舞いを導入する。\(r\) が減少するにつれて：

\begin{itemize}
  \item 大きな \(r\) では \(\alpha(r),\beta(r) \to 0\) となり \(\gamma_s \to 1\) で、標準的クーロン引力を回復する。
  \item より小さな半径では、干渉項が \(\gamma_s = 0\)（無限斥力）の点および \(\gamma_s < 0\)（力の斥力への反転）の領域を生成する。
  \item これらの離散半径 \(r_n\) は共鳴条件
  \[
  \tanh\!\left(\frac{\alpha(r_n)}{2}\right) \tan\!\left(\frac{\beta(r_n)}{2}\right) = 1
  \]
  を満たす。
\end{itemize}

力は節において未定義である。節は力の発散であって時計の凍結ではない。\(\gamma_{\mathrm{eff}}=\gamma_b^2>0\) は~\eqref{eq:gamma-eff} による。無限障壁は隣り合う井戸を隔てるが、それ自体が円軌道を与えるわけではない。

\subsection{最初のクーロン節と特性長}

\(\alpha(r)=\beta(r)=\lambda/r\) のもとで、\(\gamma_s\) の最初の正の節は \(\pi/4<x_1<1\)（\(x=\lambda/(2r)\)）にある。その最外節をボーア半径 \(a_0\) と同定すれば、特性長は \(\frac\pi2 a_0<\lambda<2a_0\) に閉じ込められる。同定 \(r_1=a_0\) は提案である。\(a_0\) 自体は外部入力である。

\subsection{クーロン型円軌道}

向心バランス \(mv^2/r=ke^2/(\gamma_s r^2)\) は
\[
v^2=\frac{ke^2}{m\,\gamma_s\,r}
\]
に書き直される。円速度が実となるのは \(\gamma_s>0\) のときに限る。斥力層では円軌道の \(v^2\) は負である。クーロン極限 \(\gamma_s=1\) では \(v^2=ke^2/(mr)\) を回復する。したがって有界円軌道は引力層——外部クーロン井戸 \(r>r_1\) と、後続の障壁に挟まれた内向き引力層——にのみ存在する。

等スケールアンザッツのもとでは共鳴条件は \(\tanh x\cdot\tan x=1\) であり、\(\gamma_s=0\) と同一であるから、第\ref{subsec:layer-spectrum}節の層スペクトルがそのまま適用される。半径は \(r_n=\Theta(1/n)\) であり、\(\Theta(n^2)\) ではない。最初の二つの節は \(r_2/r_1<1\) を満たす一方、ボーアの半径則 \(r_n=n^2 a_0\) は \(r_2/r_1=4\) を与える。等スケールの塔は内向きであり、ボーア殻は外向きである。リュードベリ系列への整合には、\(r_n=n^2 a_0\) のような別の半径則が必要である。障壁は幾何であり、水素スペクトルは別途の半径則である。

\subsection{\texorpdfstring{$Z$ 収縮}{Z contraction}}

等スケール軌跡上で、\(\ell\mapsto\ell/Z\) はすべての層半径を \(Z\) で収縮させ、\(\ell\mapsto Z\ell\) はそれらを拡大する。固定 \(\ell\) における置換 \(\alpha,\beta\propto Z/r\) は拡大写像である。それは \(Z=1\) の剖面を \(r/Z\) で評価し、節を外向きに移す。核電荷増大に伴う電子殻の観測される収縮は、同定 \(\ell(Z)=\ell/Z\) である。

共有される離散床 \(\varepsilon_N=16/(3N^2)\) を電磁結合として \(\alpha_{\mathrm{hyp}}(N)=\varepsilon_N\) と対にしてよい。CODATA の \(\alpha\) に合わせると \(729<N_*^2<732\) が強制され、したがって \(N_*\) は \(27\) と \(28\) の間にあり、\(\alpha_{\mathrm{hyp}}(27)=16/2187\) は \(\alpha\) をわずかに上回る。これは診断であり、\(\alpha\) の導出ではない。電子の重力側の高さ \(N_*^2\sim 10^{45}\) とは別チャンネルである。

\subsection{双対構造におけるエネルギー保存}

顕在ポテンシャル \(V_\text{eff}(r) = -\int F(r)\, dr\) の見かけの非保存的振る舞い、すなわち激しい振動と符号変化は、通常時空で観測される顕在ポテンシャルと、コンパクト双対時空ローター位相 \(\theta_a\) に蓄えられる真のポテンシャルとを区別することで解消される。

全エネルギーは両セクターにわたって保存される。
\[
E_\text{total} = E_\text{kinetic (usual)} + V_\text{eff}(r) + V_\text{true}(\theta) = \text{constant}.
\]
真のポテンシャル \(V_\text{true}\) はねじれ不整合スカラー \(J \propto (\phi - \theta)^2\) に比例し、隠れた貯留として働く。層遷移の間、\(V_\text{eff}\) の減少（引力から斥力へ）は双対ローターの巻きに伴う \(V_\text{true}\) の増加によって正確に補償され、その逆も成り立つ。

光子放出は、ローターがより低いねじれ状態へと巻き戻るときに蓄えられた双対位相エネルギーが解放されることに対応する。この双対の収支は、時空の離散的・粒子局所的本性を破ることなく厳密なエネルギー保存を保証する。観測されるスペクトル差は、上で述べた殻半径のボーア則を別途必要とし、等スケールの \(\gamma_s=0\) だけでは含意されない。

クーロン力はしたがって離散的ねじれ障壁と引力層における円軌道を説明する。波動関数の要請は不要である。それらの障壁を原子電子殻と同定することは提案である。層スペクトルは幾何であり、その絶対スケールとボーアの半径則は入力である。

\section{双対時空における電磁気と弱いチャンネル}
\label{sec:unification}

電磁気と弱いチャンネルは双対ローターと同じ六生成子空間を占める。それらは同一の写像ではない。双対写像 $X\mapsto Xi$ はその空間上のホッジ双対である。通常（電気、双曲）と双対（磁気、巡回）の和項を入れ替え、周期 4 をもち、$J\mapsto -J$ を送る。カイラリティは対照的に、平方が $+1$ の生成子を要する。$\mathrm{Cl}(3,1)$ の擬スカラーは $i^2=-1$ を満たすので、式 $(1\pm i)/2$ は冪等でなく、左右の射影子にはなり得ない。空間軸 $e_1$（$e_1^2=+1$）から作る相補対
\[
P_L = \frac{1 - e_1}{2},\qquad P_R = \frac{1 + e_1}{2}
\]
は冪等であり、単位元に和し、積は零である。双対性は $e_1$ を三ベクトル $-e_0 e_2 e_3$ へ送り、$e_1$ の実倍数ではない。カイラリティ軸は双対不変な直線ではない。可換な平方 $+1$ 対 $e_1$ と $e_0e_2$ の積は非零の左イデアルを生成する。そのイデアルを既約スピノル加群としては主張しない。

ファラデー係数 $(E_a,B_a)$ は双対ローターバイベクトル $\Omega_{\mathrm{biv}}$ と同じ六生成子空間を占める。
\begin{equation}
\label{eq:faraday-split}
F = F_{\mathrm{usual}}+F_{\mathrm{dual}},\qquad
F_{\mathrm{usual}}=\sum_a E_a\,i\Gamma_a,\qquad
F_{\mathrm{dual}}=\sum_a B_a\,\Gamma_a.
\end{equation}
電場は通常セクター、ブースト様、非コンパクトである。磁場は双対セクター、回転様、コンパクトである。双対性 $X\mapsto Xi$ は係数に $(E,B)\mapsto(B,-E)$ として作用する。この同定のもとで不整合スカラーはファラデー二次形式
\[
J(F)=\tfrac12(E^2-B^2),\qquad M(F)=\tfrac12(E^2+B^2)
\]
である。純電気配置は $J\ge 0$、純磁気配置は $J\le 0$ である。二つのセクターのキリング形式の符号を実験室の場で書いたものである。$E^2=B^2$ の場は釣り合い質量軌跡 $J=0$、$M>0$ にあり、真空 $M=0$ にはない。

ヘリシティ $\sigma=\pm 1$ の円偏光波（単位 $c=1$）
\[
\mathbf{E}=E_0(\hat{x}\cos\psi+\sigma\hat{y}\sin\psi),\qquad
\mathbf{B}=E_0(-\hat{x}\sin\psi+\sigma\hat{y}\cos\psi)
\]
は任意の位相 $\psi=kz-\omega t$ でヌルである。$J=0$、$E\cdot B=0$、かつ $M=E_0^2$。ビームに沿った符号付きポインティング成分は任意の位相で $\sigma E_0^2$ である。実験室の時間反転 $(E,B)\mapsto(E,-B)$ はその符号を反転し、双対性はそれを保つ。二つの局所ファラデー不変量 $J$ と $E\cdot B$ は波上で恒等的に消えるので、ヘリシティ奇数のスカラーはそれらの多項式ではあり得ない。波を背景ねじれへ重ねると $J$ は位相の第一高調波だけずれ、$J$ の四位相平均は背景の値である。線形重ね合わせは平均不整合を動かさない。

この六空間に三つの写像が作用し、混同してはならない。双対性は周期 4 をもち $J\mapsto -J$ を送る。通常--双対のパラメーター入れ替えは周期 2 をもち、同じく $J\mapsto -J$ を送り、純磁場においてのみ双対性と一致する。実験室の時間反転は $J$ を保ち $E\cdot B$ を反転する。同軸の電気生成子と磁気生成子は可換であるから、対 $(E,B)$ の同時回転は定義される。
\[
E_a(\omega)=E_a\cos\omega+B_a\sin\omega,\qquad
B_a(\omega)=-E_a\sin\omega+B_a\cos\omega,
\]
ただし $J(\omega)=J\cos 2\omega+(E\cdot B)\sin 2\omega$。双対性は特殊角 $\omega=\pi/2$ である。

$e_1$ に対し、六つの生成子は可換な三つ組 $(B_1,E_2,E_3)$ と反可換な三つ組 $(E_1,B_2,B_3)$ に分かれる。サンドイッチ $P_R X P_R$ は前者を残し後者を消す。選択は軸に依存し、ローレンツスカラーのワイル射影ではない。円偏光波はそれら二つの三つ組の位相直交和であるから、いずれの射影子もヘリシティ符号 $\sigma=\pm 1$ を選ばない。軸カイラリティは光子ヘリシティではない。

ローター $R=1+\varepsilon\Omega$ の一次サンドイッチ増分は交換子 $\Omega X-X\Omega$ であり、外積 $F\wedge X$ ではない。静止粒子に対し、純電気生成子は空間方向の蹴りを与え、すべての磁気生成子は何も与えない。$X=e_0+\mathbf{v}$ 上で交換子は四元ベクトル
\begin{equation}
\label{eq:faraday-lorentz}
FX-XF=(E\cdot v)\,e_0+(E-v\times B)
\end{equation}
である。それは実験室の時間反転場 $(E,-B)$ のローレンツ四元力である。馴染みの三元力 $q(E+v\times B)$ はサンドイッチと $B$ の符号だけ異なり、実験室の時間反転が一方を他方へ移す。静止系は仕事なしに電気蹴り $E$ を受ける。円偏光ビームに沿った速度は縦成分のない横断蹴りを与える。マックスウェル方程式は導出しない。恒等式はサンドイッチの運動学である。

電磁チャンネルと弱いチャンネルはしたがって一つの六空間に住む。双対写像は二つのセクターを入れ替え、カイラリティ射影ではない。$J$ の符号は非コンパクトな電気セクターとコンパクトな磁気セクターを区別する。粒子の四元速度上のサンドイッチは $(E,-B)$ のローレンツ力である。最小結合 $\theta_a\mapsto\theta_a+q A_a$、$\int F\,ds$ から作る拡張ローター、混合 $\omega$ からのワインバーグ角、ローター剛性のヒッグス読みは開いたままである。双対写像は V--A 結合を含意しない。

\section{双対時空コンパクト性からの暗黒物質なし銀河回転曲線}
\label{sec:darkmatter}

核と電子殻を層状にする同一の双対ローター幾何は、宇宙論的スケールではコンパクト性として展開する。慣性質量に結びついた $(\phi,\theta)$ が駆動する重力チャンネルを、双対セクターの銀河スケール $S^3$ パッチへのコンパクト化として読む。電荷に結びついた $(\alpha,\beta)$ が駆動する電磁チャンネルは、実質的により大きな、ほぼ宇宙的スケールにわたって展開する。三次元球面チャートそのものについては幾何は確定している。余接ポテンシャルはガウスの法則に従う。円速度は $v^2=(GM/R)\,f(r/R)$ である。形状 $f$ は引力区間で一意の極小をもつ。引力は $r=\pi R/2$ で終わり、$r=2R$ より厳密に前である。銀河がそのようなパッチであるなら、コンパクトから平坦への写像の系統的歪みが観測者の不足重力質量であり、平坦な回転曲線はバリオンのみから現れる。その最後の段階が提案する読みである。

\subsection{3球面としてのコンパクト双対時空}

双対ローター $R_{\text{dual}} \in \mathrm{SU}(2) \cong S^3$ は、すべての質量粒子に内在的な双対時空自由度をパラメトライズする。三つの独立な回転角 $(\theta_1, \theta_2, \theta_3)$ はコンパクト化半径 $R$ の3球面上の座標を定義し、通常時空は平坦かつ非コンパクトのままである。

対数（逆指数）写像
\[
\log : S^3 \to \mathfrak{su}(2) \cong \mathbb{R}^3
\]
は各双対ローターを平坦 $\mathbb{R}^3$ の点と同定し、3球面を半径 $\pi R$ の球へと写す。この写像は、地図学で馴染みの方位正距図法の三次元一般化である。

北極を中心とする $S^2$ の方位正距図法が極近傍の距離を忠実に表すが南極近傍で面積を壊滅的に歪める、すなわち単一の対蹠点を投影境界の全円周に写すのと同様に、$S^3$ の対数写像はヤコビアン
\[
\mathcal{J}(\chi) = \frac{\sin^2 \chi}{\chi^2},
\]
によって定量化される系統的体積歪みを導入する。ここで $\chi = r/R$ は通常時空における物理距離 $r$ に対応する測地角である。このヤコビアンは原点（$\chi = 0$、忠実な表現）で1に等しく、対蹠点（$\chi = \pi$、最大歪み）で消える。すべての標準的重力計算は暗黙に $\mathcal{J} = 1$ を仮定する。二重時空理論は、この仮定が銀河スケールで破綻することを明らかにする。

\subsection{3球面上の重力ポテンシャル：余接ポテンシャル}

重力の源であるねじれ不整合スカラー $J$ は、コンパクト双対時空上で計算される。点質量 $M$ に対する有効重力ポテンシャルは $S^3$ 上のラプラシアンのグリーン関数に支配される。球対称の場合、一意の半径方向調和関数は余接である。
\[
\Phi(r) = -\frac{GM}{R}\cot\!\left(\frac{r}{R}\right).
\]
これが $S^3$ 上のラプラス方程式を満たすことは直接検証できる。計量 $ds^2 = dr^2 + R^2 \sin^2(r/R)\,(d\vartheta^2 + \sin^2\!\vartheta\, d\varphi^2)$ をもつ測地極座標において、半径方向ラプラシアンは $\cot(r/R)$ を恒等的に消す。ガウス法則正規化は
\[
g(r) \cdot 4\pi R^2 \sin^2\!\left(\frac{r}{R}\right) = -\frac{GM}{R^2 \sin^2(r/R)} \cdot 4\pi R^2 \sin^2\!\left(\frac{r}{R}\right) = -4\pi GM.
\]
によって確認される。測地球面を通る流束は定数であるから、原点を除き $\Phi$ は半径方向に調和である。第一半球 $0<r<\pi R$ 上では、ポテンシャルが消えるのは $r=\pi R/2$ のときに限る。引力は三次元球面の赤道で終わる。

$r \ll R$ の極限では、余接は
\[
\cot\!\left(\frac{r}{R}\right) = \frac{R}{r} - \frac{r}{3R} - \frac{r^3}{45R^3} - \cdots\,,
\]
と展開され、
\[
\Phi(r) \approx -\frac{GM}{r} + \frac{GM\,r}{3R^2} + \mathcal{O}\!\left(\frac{r^3}{R^4}\right)
\]
を与え、主要項として標準ニュートンポテンシャルを回復する。高次補正は純粋に $S^3$ の曲率から生じ、非コンパクト化極限 $R \to \infty$ で消える。

\subsection{重力の幾何的増強}

$S^3$ 上の重力加速度
\[
g(r) = -\frac{d\Phi}{dr} = -\frac{GM}{R^2 \sin^2(r/R)}
\]
は、平坦空間ニュートン加速度 $g_{\text{N}} = -GM/r^2$ を増強因子
\[
\eta(r) \equiv \frac{g_{S^3}(r)}{g_{\text{N}}(r)} = \left[\frac{r/R}{\sin(r/R)}\right]^2
\]
だけ上回る。この因子は方位正距図法の計量歪みの平方そのものである。すなわち $\eta\,\mathcal{J}=1$ である。$S^3$ 上の測地半径 $r$ の球面を通る重力フラックスは面積 $4\pi R^2 \sin^2(r/R)$ を張り、これは平坦空間面積 $4\pi r^2$ より小さい。フラックスは集中し、重力は強められる。不可視物質によってではなく、コンパクト双対時空の曲率によってである。区間 $(0,\pi)$ 上で増強は厳密に増大し、1より大きい。ポテンシャルの零点では $\eta(\pi/2)=\pi^2/4$ である。

引力半球上の代表的な窓：$r/R=0.1$ で $1.003<\eta<1.004$、$r/R=1$ で $1.40<\eta<1.48$。値 $r/R=2$ はすでに $\pi/2$ を超えており、回転曲線上の点ではない。

\subsection{平坦回転曲線の創発}

点質量 $M$ のまわりの円軌道にある試験粒子に対し、三次元球面チャート上で
\begin{equation}
\label{eq:s3-circular}
v^2(r)=r\,|g(r)|=\frac{GM}{R}\,f(r/R)=\frac{GM}{r}\,\eta(r/R),
\end{equation}
ここで $f(x)=x/\sin^2 x$。$v$ の平坦さは $f$ の定常性である。光度円盤の外側では $M(r)\approx M_{\text{tot}}$ であり、ケプラー因子 $GM_{\text{tot}}/r$ は $r^{-1}$ で減少する。厳密に増大する増強 $\eta$ がこの減少に対抗する。結合した形状は $f$ そのものである。

引力区間 $(0,\pi/2)$ 上で形状 $f$ は一意の臨界点をもち、それは $(1.14,1.20)$ における $\tan x=2x$ の一意根 $x_0$ である。その根で $f(x_0)=x_0+1/(4x_0)$ であり、この値 $f_0$ は $(0,\pi/2)$ 上の $f$ の一意な極小である。
\[
\frac{135}{100}<f_0<\frac{141}{100}.
\]
その極小が台地の幾何的起源である。内側のケプラー的減少が食い止められたのち、$v^2$ は $r=x_0 R$ の近傍で $(GM/R)f_0$ 付近に留まる。$x_0<\pi/2<2$ であるから、引力パッチは $r=\pi R/2$ で終わり、$r=2R$ より厳密に前である。点質量チャート上の三領域はしたがって次である。

\begin{itemize}
  \item \textbf{内側領域}（$x\ll 1$）：ニュートン回復。上昇する $M(r)$ によって修正されたケプラー振る舞い。
  \item \textbf{台地}（$x\sim x_0$）：$f$ の一意な極小。すでに $1.40<f(1)<1.48$ は $f_0$ に近い。
  \item \textbf{上昇と反転}（$x_0<x<\pi/2$）：$f$ は上昇し、$x=\pi/2$ でポテンシャルは消え引力は終わる。半径 $r=2R$ はすでに斥力半球にある。
\end{itemize}

\subsection{バリオン的タリー--フィッシャー関係とコンパクト化半径}

台地における漸近円速度は
\[
v_{\text{flat}}^2 \sim \frac{GM_{\text{tot}}}{R} \cdot f_0,
\]
を満たす。ここで $f_0$ は $(0,\pi/2)$ 上の $f$ の一意な極小である。コンパクト化半径が全囲まれ質量とともに
\[
R = \sqrt{\frac{GM_{\text{tot}}}{a_0}}
\]
とスケールするなら、ここで $a_0 \approx 1.2 \times 10^{-10}\;\mathrm{m/s^2}$ は外部の観測的加速度スケール（バリオン的タリー--フィッシャー／MOND スケール）であり、双対ローター代数から導出された量ではなく入力として扱う。すると
\[
v_{\text{flat}}^4 = G M_{\text{tot}} \, a_0 \, f_0^2
\]
となる。これは、そのスケーリングを与えたときのチャートの恒等式としてのバリオン的タリー--フィッシャー関係である。スケーリング $R \propto M^{1/2}$ は、より質量の大きい銀河がより大きな双対時空パッチをもつことを含意する。双対ローター代数からの $a_0$ の導出は主張しない。

\subsection{円偏光電磁場の双対ローターへの理論的結合}

電磁場は二つの時空にわたって自然に分割される。

\[
F = F_{\text{usual}} + F_{\text{dual}},
\]

ここで

\[
F_{\text{usual}} = \mathbf{E} \cdot (iI, iJ, iK) \quad (\hat{p}^2 = +1:\ \text{ブースト様、非コンパクト}),
\]

\[
F_{\text{dual}} = \mathbf{B} \cdot (I, J, K) \quad (\hat{q}^2 = -1:\ \text{回転様、コンパクト}).
\]

電場成分 $\mathbf{E}$ は通常時空ブースト生成子を占め、磁場成分 $\mathbf{B}$ は双対時空回転生成子を占める（~\eqref{eq:faraday-split}）。実験室の時間反転 $(E,B)\mapsto(E,-B)$ は、双対性とも通常--双対のパラメーター入れ替えとも異なる対合である。

ヘリシティ $\sigma = \pm 1$ で $z$ に沿って伝播する円偏光波に対して、

\[
\mathbf{E} = E_0 (\hat{x} \cos(kz - \omega t) + \sigma \hat{y} \sin(kz - \omega t)), \quad \mathbf{B} = \frac{E_0}{c} (-\hat{x} \sin(kz - \omega t) + \sigma \hat{y} \cos(kz - \omega t)).
\]

任意の位相においてその波はヌルである。$J=0$、$E\cdot B=0$、かつ $E_0\neq 0$ ならば $M=E_0^2$ である。線形ファラデー係数はいずれも位相の第一高調波なので、四位相平均は消え、
\[
\langle F_{\mathrm{usual}}\rangle=\langle F_{\mathrm{dual}}\rangle=0.
\]
とくに $\sigma E_0^2 K$ に比例する平均双対場は存在しない。ヘリシティ奇数かつ一定なのは双一次のポインティング成分 $(E\times B)_z=\sigma E_0^2$ である。波を背景ねじれへ重ねても平均 $J$ は動かず、ファラデー混合は波から $J$ を作れない。双対和項の一次静止サンドイッチは任意のファラデー場、円偏光波を含めて消える。波そのものの静止サンドイッチは振動する電気蹴りであり、その四位相平均は消える。ビーム方向の速度は縦成分のない横断蹴りを与える（~\eqref{eq:faraday-lorentz}）。軸射影子 $P_{L,R}$ もヘリシティを取り出せない。

したがって粒子不整合のヘリシティ依存駆動は、$F$ の局所スカラーでも、線形重ね合わせでも、$F_{\mathrm{dual}}$ の一次静止サンドイッチでも、軸カイラリティ射影でも、ビーム方向のローレンツ蹴りでもない。そのような駆動は余分な構造——好ましい軸、ポテンシャル、あるいは粒子の双対位相——を要する。以下の模型では、ヘリシティ奇数の双一次量 $(E\times B)_z=\sigma E_0^2$ が双対位相駆動の候補源であり、右円偏光（$\sigma=+1$）は引力不整合（$J>0$）を強化し、左円偏光（$\sigma=-1$）はそれに対抗する。

作業模型における結合は経路順序指数として書かれる。

\[
R_{\text{dual}} \to \mathcal{P} \exp\!\left( \frac{1}{2} \int (\theta_a \Gamma_a + e \lambda A_a \Gamma_a) \, ds \right),
\]

ここで双対生成子 $\Gamma_a$ が相互作用を媒介する。共鳴近傍では、双対位相は
\[
\dot{\theta} = \kappa \sigma E_0^2 \sin(\omega t - \theta + \delta_\sigma)
\]
として模型化され、ねじれ不整合角のコヒーレント励起はこの提案模型の内部でのみ与えられる。

\theta \in \frac{2\pi}{N} \mathbb{Z},
\]
ここで $N \gg 1$ は双対時空のコンパクト化スケールを定める非常に大きな整数である（典型的にはプランク単位における粒子の静止質量に比例する）。通常時空ラピディティは連続のままである。
\[
\phi \in \mathbb{R}.
\]

この非対称は理論的整合性のために要求される。
\begin{itemize}
  \item 双対時空は楕円的（$\hat{q}^2 = -1$）であり本質的にコンパクトである。その離散化は $R_{\text{dual}}$ によってパラメトライズされる $S^3$ の $4\pi$ 周期位相を直接反映する。これはニュートン--ウィグナー局在化問題を解消し自然な量子離散性を与えるために本質的な有限位相体積を提供する。
  \item 通常時空は双曲的（$\hat{p}^2 = +1$）であり内在的に非コンパクトである。したがって $\phi$ の連続性は巨視的極限における完全ローレンツ群を保つ。
\end{itemize}

ねじれ不整合ローター $\Omega = R_{\text{usual}}^\dagger R_{\text{dual}}$ はしたがって連続な通常成分と離散な双対成分を結合する。スカラー $J$ は許容配置上でのみ $|J|\le\Jbound$ で有界である。双対角のみの離散化は有界を含意しない。非負ラピディティなしの主枝条件は反例を許し、連続な通常セクターラピディティは非有界である。連続体誘起の特異点が排除されるのは、許容錐が課された後に限られる。離散トーラス $(\mathbb{Z}/N\mathbb{Z})^6$ 上のローター像は有限である。スケールした格子配置の非零巻数は実スケール許容と両立しない。$4\mid N$ のとき格子は端点 $\Jnorm=\pm 1$ に達し、そうでなければ許容上界は厳密である。

ねじれ層にわたる有効ローレンツ因子において臨界的問題が生じる。それは典型的に
\[
\gamma_{\text{eff}} \propto D_N(\delta\theta) \equiv \frac{\sin(N \delta\theta / 2)}{N \sin(\delta\theta / 2)}
\]
の形の同期関数として現れ、ここで $\delta\theta$ はねじれ不整合角、$D_N$ は（正規化された）ディリクレ核である。分母は格子 $\delta\theta \in 2\pi \mathbb{Z}$ 上で正確に消える。

そのような各点で分子 $\sin(N \cdot k\pi)$ も消える（任意の整数 $N$、素数でも合成数でも）ため、見かけの特異点は実際にはディリクレ核型の除去可能な $0/0$ である。標準的なロピタル評価は有限極限
\[
\lim_{\delta\theta \to 2\pi k} D_N(\delta\theta) = \pm 1 \qquad (k \in \mathbb{Z})
\]
を与える。したがって同期関数はコンパクト格子全体で有界であり、古典連続体極限 $N \to \infty$ は病理なしに回復される。

したがってディリクレ核は任意の大きな正整数 $N$ に対して有界であり、素数性は要求されない。除去可能特異点をロピタル値で埋めれば $|D_N(\theta)|\le 1$ であり、すべての格子点で $D_N=\pm 1$ である。$N$ と粒子質量スペクトルの関係、およびゼータ正則化積 $\prod_p p\to 4\pi^2$ は開いたままである。$4\pi^2$ を双対ローター周期 $2\pi$ の平方と読むことは整合性の注記であり、質量スペクトルの導出ではない。

\section{双対ローター動力学とド・ブロイ位相の幾何的起源}
\label{sec:dualrotordynamics}

不整合スカラー $J$ は古典場理論における重力作用密度として提案される。同時に、個々の質量粒子の内部角に対するポテンシャルとしての粒子内在的読みも許す。その読み、および以下のド・ブロイ同定は提案である。

小さな不整合角に対し、キリング形式不変量は
\[
J \approx \frac{1}{2} \sum_{a=1}^3 \delta\phi_a^2
\]
と展開される。ここで $\delta\phi_a = \phi_a - \theta_a$ は各ブースト--回転平面におけるねじれ不整合角である。静止質量 $m$ を双対セクターの剛性定数として取り込むことはモデリング上の選択であり、代数からの $m$ の導出ではない。
\[
J = \frac{1}{2} m \sum_{a=1}^3 (\phi_a - \theta_a)^2.
\]

単一粒子の内在的ローター角に対して書かれた有効作用を考える。
\[
S_{\text{particle}} = \int \left[ \frac{1}{2} \sum_{a=1}^3 \dot{\phi}_a^2 - \frac{1}{2} \sum_{a=1}^3 \dot{\theta}_a^2 - \frac{m}{2} \sum_{a=1}^3 (\phi_a - \theta_a)^2 \right] dt.
\]
運動項の反対符号は書かれた模型の一部であり、ローターのユニタリ性から演繹されたものではない。

このラグランジアンのオイラー--ラグランジュ方程式は
\[
\ddot\phi=-m(\phi-\theta),\qquad \ddot\theta=-m(\phi-\theta).
\]
である。したがって不整合 $\delta=\phi-\theta$ は自由である：$\ddot\delta=0$。書かれた作用は振動子 $\ddot\delta+m\delta=0$ を与えない。並べて書かれることのある近傍の系
\[
\ddot\phi=m(\phi-\theta),\qquad -\ddot\theta=m(\phi-\theta),
\]
は不整合を暴走させ $\ddot\delta=2m\delta$ となり、同様に振動子ではない。

振動子が現れるのは、両方の運動項の符号を正にとったときである。修正密度 $L=\tfrac12\dot\phi^2+\tfrac12\dot\theta^2-\tfrac m2(\phi-\theta)^2$ のオイラー--ラグランジュ方程式は $\ddot\phi=-m(\phi-\theta)$ および $\ddot\theta=m(\phi-\theta)$ であり、したがって
\[
\ddot\delta+2m\delta=0.
\]
これは別の作業模型であり、書かれた作用ではない。その周波数は $\sqrt{2m}$ である（$\hbar = c = 1$ の自然単位）。一様運動する自由粒子に対し、通常ラピディティは一定率 $\dot{\phi}_a=\gamma v_a/c$ で発展するとモデル化される。一般解は
\[
\delta\phi_a(t) = A_a \sin(\sqrt{2m}\, t + \psi_a).
\]
である。低エネルギー非相対論的レジームでは、急速なコンプトン周波数振動は平均してゼロになると仮定され、固有時に比例する位相の遅い線形蓄積を残す。$\hbar$ および $c$ を復元すると、蓄積位相は
\[
\int \delta\phi_a \, dt \propto \frac{E t - \mathbf{p} \cdot \mathbf{x}}{\hbar}
\]
と予想され、これは物質波のド・ブロイ位相である。この粒子内在的作用の多数粒子にわたる集団平均は、$J$ の巨視的積分を回復すると提案する。その平均は $J$ とワイツェンベック密度 $T$ の同一視ではない。書かれた作用は量子理論への調和的橋渡しを与えない。同符号模型が、ここで比較した三系のうち唯一の振動子である。

\section{量子重力と完全統一に向けて}
\label{sec:quantumgravity}

これまでに提示した古典定式化は、重力を $\mathbb{H}\otimes_{\mathbb{R}}\mathbb{H}\cong\mathrm{Cl}(3,1)$ に符号化された粒子内在的な通常・双対時空のねじれ不整合として扱う。提案する作用はパラメータ空間スカラー $J$ を用いる。アインシュタイン--ヒルベルト積分とは同定しない。

双対ローター $R_\text{dual}=\exp(\theta/2\,\hat q)$ は $\mathrm{SU}(2)$ のスピン $1/2$ 回転演算子である。したがって双対セクター位相 $\theta$ は量子状態をパラメトライズする。$\mathbb{C}^2$ 上で $\exp\bigl(\sum_a(\theta_a/2)(-i\sigma_a)\bigr)$ として表現され、ユニタリかつ行列式 $1$ であり、したがって $\mathrm{SU}(2)$ の元である。双対時空のコンパクト性（$\theta\bmod 4\pi$）により、これらの位相はコンパクト多様体上に住む。各粒子の状態 $|\psi\rangle$ は $R_\text{dual}$ のユニタリ位相部分に対応する。$\mathrm{Cl}(3,1)$ 極小左イデアルのヒルベルト空間完備化はここでは構成しない。

位置および運動量演算子、ならびにそれらの間の不確定性関係は導出しない。特異点は第\ref{sec:gravity}節の上界により許容錐上で排除される。第\ref{subsec:quasi-horizon}節の準地平は、飽和シュヴァルツシルトチャート上でのその上界の読みである。$\mathrm{Cl}(3,1)$ スピノルの明示的ヒルベルト空間、および不整合動力学の完全な量子化は開いたままである。

したがって量子重力は別理論ではない。同一の16次元代数の双対ローター運動学であり、ヒルベルト空間構成としてはなお不完全である。

\section{結論}
\label{sec:conclusions}

アインシュタインとともに始まった一世紀は、重力を連続体の曲率として語ることを教えてきた。その語りは巨視的な記述として正確であり、いまも正確である。しかし連続体がなぜ曲がるのか、なぜ同一の現象が加速度のもとで慣性として現れるのかは、そこでは問われない。本稿は連続体を原始的対象とすることを拒んだ。自律的な舞台は存在しない。各質量粒子は、$\mathrm{Cl}(3,1)$ と同型な十六実次元の双四元数代数の内部に、通常と双対というミンコフスキーセクターの対を運ぶ。両者を結ぶ写像は時間の矢を反転し、ミンコフスキーノルムは保たれる。重力とはその対のねじれであり、粒子自身に属する二つのローターの不整合である。

相対ローターが恒等元であるのは、二つのローターが一致するときに限る。不整合を測るローレンツ不変スカラー $J$ は許容錐上で有界であり、$J$ の消滅はローターの一致を強制しない。任意の静的動径ブースト・チャートにおいて $J$ は遠平行重力のワイツェンベックねじれ $T$ と閉じた関係で結ばれ、外域シュヴァルツシルト幾何はその一意な真空の場合である。両者が一致するのは平坦極限に限る。実動径ブーストは斥力を生まず、斥力層は楕円セクタに属し、その深さは有界である。二つのローターが同一の尺度を共有するとき $J$ は消えるが、干渉はなお交替する。ゆえに強場重力の層の秩序は $J$ ではなくその干渉である。同一の代数が電磁気を収容し、ファラデー係数は双対ローターの六生成子空間にあり、サンドイッチ増分はローレンツ四元力である。三次元球面チャート上では円速度は $v^2=(GM/R)f(r/R)$ であり、形状 $f$ は $(0,\pi/2)$ で一意の極小をもち、引力は $\pi R/2$ で終わり $r=2R$ より前である。いずれも背景多様体を必要としない。

層状相を強い力と同定すること、銀河が双対セクターの三次元球面パッチであること、したがってこのコンパクト性が平坦な回転曲線を説明すること、双対セクターのコヒーレント励起が重力を工学しうること、初期の双対動学がバリオン非対称の源であること、同一の六空間からマックスウェル方程式・ワインバーグ角・ローター剛性のヒッグス読みを回復すること、不整合振動子をド・ブロイ位相と読むこと、そして双対ローターのヒルベルト空間量子化が理論を完結させること——これらを提案してきた。それらは幾何の読みである。重力の制御可能性は予想である。

すでに天空に問いかけうることは、控えめで鋭い。真の地平の代わりに、有限な赤方偏移の床が期待される。球対称なねじれ星の中心では、重力時間膨張は消えるはずである。銀河が三次元球面パッチであるなら、回転曲線は見えない質量によってではなく $r\sim x_0 R$（$x_0\in(1.14,1.20)$）付近でプラトーをなし、$\pi R/2$ で反転する。天の川の代入質量では台地は $9$--$11\,\mathrm{kpc}$ 付近、反転は $12$--$15\,\mathrm{kpc}$ 付近である。相次ぐ障壁半径の比は純粋な数であり、特性長が相殺されるため、核スケールでも恒星スケールでも同一である。

この存在論が正しければ、世界の幾何は物質に先立たない。それはスピンや電荷と同様、粒子の属性であり、天空に見える曲率は双対ローターの集合的なねじれである。連続体は大きな尺度における有用なフィクションのままである。残る仕事は、空虚な舞台をより巧みに曲げることではない。すでに手中にある代数から、物質の対をなすローターが、われわれの見る世界をいかに組成するかを学ぶことである。
