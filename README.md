# DstDiophantine

Lean 4 formalization of **Double Spacetime Theory** (DST), together with an amplification programme — and an open **proof challenge** — for classical Diophantine conjectures.

The machine-checked core is an algebraic bound and a shared no-go calculus. Unconditional statements of Fermat’s Last Theorem, Beal’s conjecture, the abc conjecture, the Riemann Hypothesis, Goldbach, Polignac, or Collatz are **not** claimed.

## What this is

DST encodes gravity and arithmetic in one biquaternion algebra $\mathbb{H} \otimes_{\mathbb{R}} \mathbb{H} \cong \mathrm{Cl}(3,1)$, then lifts additive structure into projective geometric algebra $G(3,1,1)$. This repository machine-checks the algebraic layer of that programme:

- Clifford / PGA generators, motors $M = RT$, and the torsional scalars $J$ and $J_{\mathrm{norm}}$
- the admissible bound $|J_{\mathrm{norm}}| \le 1$ (equivalently $|J| \le 3\pi^2/8$)
- a faithful embedding of integers via rotors and null translators
- problem-independent amplification no-go theorems on the discrete torus

Entry point for this Diophantine path: [`DstDiophantine/Basic.lean`](DstDiophantine/Basic.lean).

## What this is not

Each classical conjecture is reduced to a **solution-to-witness bridge** that Lean does not prove. The repository therefore contains:

- named hypotheses such as `FermatAdmissibleBridge` and `BealModularBridge`
- finite computational certificates (`native_decide` searches on bounded boxes)
- explicit `axiom`s for classical results that mathlib does not provide (Wiles’ FLT, Mihăilescu, Darmon–Merel cubes, the $(n,n,5)$ signature)

Closing a bridge, or replacing an axiom with an internal proof, is the proof challenge.

## Double Spacetime Theory

DST rejects a single shared spacetime continuum. Each massive particle carries its own pair of compact Minkowski structures inside the 16-real-dimensional biquaternion algebra:

- **usual** spacetime with basis $(j, kI, kJ, kK)$
- **dual** spacetime with basis $(k, jI, jJ, jK)$

The dual map $X \mapsto Xi$ reverses the arrow of time while preserving the Minkowski norm. Lorentz transformations are generated by commuting rotors on each sector. Gravity and inertia are read as **torsional mismatch** between those rotors,

$$
\Omega = R_{\mathrm{usual}}^{\dagger}\, R_{\mathrm{dual}},
\qquad
J = \tfrac12\sum_{a=1}^{3}(\alpha_a^2 - \beta_a^2),
$$

not as curvature of a background manifold. Algebraic $J$ is **not** identified with the Weitzenböck teleparallel scalar $T$.

The full physical development is in [`papers/double-spacetime-theory.tex`](papers/double-spacetime-theory.tex). The PGA lift $G(3,1,1)$ (null translators, ten bivector generators, motor unitarity) is in [`papers/dst-pga.tex`](papers/dst-pga.tex).

## The Diophantine proof challenge

Integers embed into PGA motors. A power-sum equation such as $a^p + b^p = c^p$ or $A^x + B^y = C^z$ becomes the algebraic condition that the corresponding motor is the identity (`powerSumMotor = 1`). Dual-spacetime rapidities are discretized to a finite torus $(\mathbb{Z}/N\mathbb{Z})^6$, so each problem is a search over an **admissible** lattice subject to $|J_{\mathrm{norm}}| \le 1$.

The shared programme, developed in [`DstDiophantine/Framework/`](DstDiophantine/Framework/) and spelled out in [`papers/dst-diophantine.tex`](papers/dst-diophantine.tex), has three layers:

1. **Faithful encoding** — additive relations as null-translator motors (proved).
2. **Amplification no-go** — a seed that amplifies past the admissible bound cannot exist (proved, problem-independent).
3. **Bridge** — a classical solution would produce such a witness (open).

The challenge is layer 3: prove a `*AdmissibleBridge` or `*ModularBridge`, or show that the live residual / dual-axis encoding already forbids classical solutions.

## Repository layout

```
DstDiophantine/
  Basic.lean          Diophantine public API (does not re-export Gravity or Logic)
  Algebra/            PGA, Cl(3,1), discrete torus, J / JNormalized, motors
  Embedding/          integer rotors, null translators, height, Fermat motor
  Framework/          power-sum encoding, lattice, descent, amplification, search
  Theorems/           problem-specific layers (see table above)
  Logic/              Dual Spacetime 4-valued logic (D4L) — parallel track
  Gravity/            PGA–TEGR chart layer — parallel track
  CGA.lean            1D conformal probe — parallel track
papers/               English TeX sources (Japanese counterparts in papers/japanese/)
```

Import `DstDiophantine.Basic` for the Diophantine path. The gravity, logic, and CGA modules are independent tracks; they are not pulled in by `Basic.lean`.

## Build

Requires [elan](https://github.com/leanprover/elan) and the toolchain pinned in [`lean-toolchain`](lean-toolchain) (`leanprover/lean4:v4.34.0-rc1`). mathlib is the matching revision in [`lakefile.toml`](lakefile.toml).

```bash
lake build
```

CI runs the same build via [lean-action](https://github.com/leanprover/lean-action) on every push and pull request ([`.github/workflows/lean_action_ci.yml`](.github/workflows/lean_action_ci.yml)).
