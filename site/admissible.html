3. A ceiling on the twist3. ねじれには上限がある

DST places the rapidities on a compact range. On the admissible cone every axis has αa, βa ≥ 0 with αa + βa ≤ π/2. On that cone the height J can never exceed 3π²/8 in size. Dividing by that value gives Jnorm, with |Jnorm| ≤ 1. This bound is proved, and it is sharp.DSTではラピディティを有限の範囲に置きます。許容錐では、各軸で αa, βa ≥ 0 かつ αa + βa ≤ π/2 です。この上では高さ J の大きさは 3π²/8 を超えません。この値で割ったものが Jnorm で、|Jnorm| ≤ 1 となります。この上限は証明済みで、ぎりぎり到達できる（最良の）値です。

Many sources: internal sum vs expressed state多数の源：内部の和と表出状態

Each source contributes a small twist, written as a source bivector in a six-dimensional coefficient space (three axes, each with a boost part and a rotation part). Many sources add there in plain vector addition: the order does not matter, and that internal sum has no ceiling — the same quadratic height J, evaluated on the sum alone, can exceed 3π²/8.各源は小さなねじれを寄せます。それは六次元の係数空間（三つの軸、それぞれにブースト成分と回転成分）の源バイベクトルとして書けます。多数の源はそこで普通のベクトル和として足されます。順序は関係なく、その内部の和に天井はありません。同じ二次の高さ J を和だけの上で評価すれば、3π²/8 を超えうます。

What a particle expresses is different. On each axis, take the triangle α ≥ 0, β ≥ 0, α + β ≤ π/2. The expressed coefficients are the admissible point closest to the internal sum on that triangle, axis by axis. Inside the triangle the closest point is the sum itself, so a weak collection of sources expresses the ordinary sum of their twists. Past the edge α + β = π/2 the expressed sum pins at π/2 while the expressed difference keeps tracking the internal difference; when that difference reaches π/2 the state locks to a pure-boost or pure-rotation corner, and more of the same kind of source changes nothing expressed.粒子が表出するものは別です。各軸で三角形 α ≥ 0、β ≥ 0、α + β ≤ π/2 を考えます。表出される係数は、軸ごとに、その三角形上で内部の和に最も近い許容点です。三角形の内側では最近点は和そのものなので、弱い源の集まりはねじれの普通の和を表出します。辺 α + β = π/2 を越えると表出された和は π/2 に固定され、表出された差は内部の差を追い続けます。その差が π/2 に達すると状態は純ブーストまたは純回転の角にロックし、同じ種類の源をさらに足しても表出は変わりません。

Thus |J| of the expressed configuration stays at most 3π²/8 even when many sources pile up, while the internal quadratic can grow without bound. Aligned sources add rapidities, not values of J: n pure π/2 boosts on one axis have internal J = n²π²/8 but express J = π²/8 for every n ≥ 1; two π/4 boosts each have J = π²/32 but together express one π/2 boost with J = π²/8, not π²/16.したがって表出された配置の |J| は、源がいくら重なっても高々 3π²/8 のままです。一方、内部の二次式は上限なく大きくなりえます。揃った源が足し合わせるのは J の値ではなくラピディティです。一軸上の π/2 の純ブーストを n 回重ねると内部 J = n²π²/8 ですが、n ≥ 1 では表出 J = π²/8 です。ラピディティ π/4 のブーストが二つあるとき、それぞれ J = π²/32 ですが、まとめて表出するのは J = π²/8 の一つの π/2 ブーストであり、π²/16 ではありません。

Gravity uses the same split. Summing weak sources on the admissible cone expresses their twists additively (section 2, fixed compactification radius). When the patch radius tracks enclosed mass instead, the acceleration relation grows slower than Newton: strictly subhomogeneous and strictly subadditive, so low-acceleration superposition fails even while the internal six-space still adds freely. High acceleration stays near inverse-square; the transition is fixed once a₀ is supplied as input.重力も同じ二層構造。許容錐上で弱い源を足すとねじれは加法で表出されます（第2節、コンパクト化半径固定）。パッチ半径が包まれた質量に従う場合は、加速度関係はニュートンより遅く伸び、厳密に次同次でも次加法でもなく、低加速度では重ね合わせが破れます。内部の六空間の自由な和とは別です。高加速度では逆二乗に近く、a₀ を入力として与えれば遷移は固定されます。

Not claimed here: a Newtonian multi-body force law derived from this bookkeeping; coefficient-wise Faraday addition in the electromagnetic six-space is unchanged. See section 3 for the proved ceiling on expressed |J|. Galaxy readings are model theorems, not an observational dark-matter verdict.ここでは主張しない：この台帳からニュートン型の多体の力の法則を導くこと；電磁気の六空間における係数ごとのファラデー加法は変わらない。表出 |J| の証明済み上限は第3節を参照。銀河の読みはモデル内の定理であり、観測上のダークマター判定ではありません。

What surrounding matter fixes周囲の物質が決めるもの

Mach asked whether inertia comes from the rest of the universe. In DST the answer is split cleanly between what twist is expressed and how strongly that twist drives motion. Surrounding matter fixes the first: each source contributes a small twist, the sources add in coefficient space in an order that does not matter, and the particle expresses the admissible point nearest that combined sum — the same nearest-point rule as in the subsection above. What surrounding matter does not fix is the stiffness with which an expressed mismatch accelerates the particle; that stiffness is a separate input, not read off from the source list.マッハは、慣性が宇宙の残りから来るのかと問いました。DST では答えは、どのねじれが表出するかとそのねじれがどれだけ強く運動を駆動するかにきれいに分かれます。周囲の物質が決めるのは前者です。各源は小さなねじれを寄せ、源は係数空間で足され、その順序は関係ありません。粒子はその和に最も近い許容点を表出します — 上の小節と同じ最近点の規則です。周囲の物質が決めないのは、表出された不整合が粒子を加速させる硬さです。その硬さは別の入力であり、源のリストからは読み取れません。

With no sources at all, the expressed state is the origin: every rapidity vanishes on the admissible cone. The dynamics then assign no angular acceleration, however large the stiffness might be — so read physically, the pull we associate with inertia does not appear in an empty universe. That is a different claim from general relativity, where spacetime can exist without matter and still carry geometry and structure; Mach’s principle in the strict sense remains unfulfilled there. DST instead ties the source of the expressed mismatch to matter, while keeping stiffness as its own datum.源がまったくないとき、表出状態は原点です。許容錐上ではすべてのラピディティが消えます。硬さがどれだけ大きくても、力学は角加速度を割り当てません — 物理的に読めば、慣性に結びつける引きは空っぽの宇宙には現れません。これは一般相対性理論とは異なる主張です。そちらでは、物質がなくても時空は存在し、幾何や構造を担えます。厳密な意味でのマッハの原理はそこでは満たされません。DST は表出された不整合の源を物質に結びつけつつ、硬さは別の与えられた量として保ちます。

Aligned boosts from sources illustrate the ceiling on motion. While the expressed lag stays below the admissible wall, each aligned pure boost adds its contribution to the common acceleration; once the wall is reached, adding more of the same kind leaves the acceleration fixed at the saturated value. The twist measure J does not add the same way: two moderate boosts can express one larger lag with a single J on the cone, not the sum of their J values. Accelerations from aligned sources add up to the ceiling; the twist measure does not. A mismatch the particle already carries in its own rotors is not the same reading as mismatch supplied by sources — it is part of the particle’s angles — yet it still drives acceleration through the same stiffness. The machine-checked development in the gravity part of the repository is the formal record for these statements.源からの揃ったブーストは、運動に対する上限の働きを示します。表出された遅れが許容の壁より内側にある間、揃った純ブーストごとに共通加速度への寄与が足されます。壁に達すると、同じ種類をさらに足しても加速度は飽和した値のままです。ねじれの尺度 J は同じように足されません。二つの中程度のブーストが、錐上では一つの大きな遅れと一つの J として表出され、J の値の和にはなりません。揃った源からの加速度は上限まで足されます。ねじれの尺度は足されません。粒子が自分のローターですでに運ぶ不整合は、源が供給する不整合と同じ読み取りではありません — 粒子自身の角度の一部です — が、同じ硬さを通じて依然として加速を駆動します。リポジトリの重力部分の機械検証された展開が、これらの記述の形式的な記録です。

This Mach-style reading does not derive stiffness (what we call mass in laboratory language), does not replace Newton’s force–mass–acceleration law, and does not cap proper accelerations measured in a laboratory; it separates source-fixed expression from stiffness-driven response on the admissible cone.このマッハ型の読み取りは、硬さ（実験室の言葉では質量）そのものを導きません。ニュートンの力と質量と加速度の法則の代わりにもなりません。実験室で測る固有加速度に上限を設けません。許容錐上で、源が決める表出と、硬さが駆動する応答を分ける、という内容です。

What passes through the wall and what overflows壁を通るものと溢れるもの

When many sources pile up, the admissible cone does not pass everything through unchanged. What does pass is the lag — on each axis, the difference between the usual and dual rapidities. The common acceleration in the written dynamics follows that lag alone, not the full uncapped internal sum. The sum of the two sectors on an axis is capped at the wall of the admissible triangle; only the lag keeps tracking the internal difference until it too runs out of room.源がたくさん重なると、許容錐はすべてをそのまま通しません。通るのは遅れ — 各軸での通常と双対のラピディティの差 — です。記述された力学の共通加速度は、上限のない内部の和ではなく、その遅れだけに従います。一軸での二セクターの和は許容三角形の壁で抑えられます。遅れだけが、内部の差を追い続け、それも余地を失うまで。

Balanced sources — the same increment added to both sectors on an axis — illustrate the split. Internally the pile can grow without bound along the balanced direction, yet the lag, the expressed mismatch, and the unsigned mass on the cone can all stay fixed, and the acceleration does not change. Saturation appears only when the lag itself no longer fits in the triangle, as with aligned pure boosts where lag and sum move together. That shielding-like saturation has no analogue in the standard linear superposition of weak gravity, where fields add in proportion; on this point DST and standard theory reach different conclusions about what kind of property superposition is.釣り合った源 — 一軸で両セクターに同じ増分を足す場合 — がこの分離を示します。内部的には釣り合った方向に沿って山は上限なく大きくなれますが、遅れも表出された不整合も錐上の符号なし質量も固定のままで、加速度も変わりません。飽和は、遅れ自体が三角形に収まらなくなったとき — 遅れと和が一緒に動く、揃った純ブースト — に現れます。このシールドのような飽和は、弱い重力の標準的な線形重ね合わせ — 場が比例して足される — には対応物がありません。重ね合わせがどんな性質かについて、DST と標準理論はここで異なる結論に着きます。

Resting but heavy: where mass sits静止しているのに重い：質量はどこにある

Mass in DST is not the same thing as mismatch. On a state where both sectors carry the same rapidity on every axis, the twist measure J vanishes, the stiffness potential vanishes, and the written action assigns no acceleration — a genuinely resting configuration in the Mach sense above. Yet the unsigned mass need not be zero: it is carried in the common scale of those matched rapidities. The two rotors need not coincide; the body can still be internally torsioned while J stays zero.DST では質量と不整合は同じものではありません。すべての軸で両セクターが同じラピディティを運ぶ状態では、ねじれの尺度 J は零になり、硬さポテンシャルも零になり、記述された作用は加速度を割り当てません — 上のマッハの意味での本当の静止です。それでも符号なし質量は零でなくてよく、一致したラピディティの共通の尺度として載ります。二つのローターは一致する必要はなく、J が零でも内部にはねじれが残りえます。

The time-reversing dual map used in the antiparticle story (chapter 5) acts differently on mass and mismatch. It fixes only the completely empty configuration, where mass vanishes. On a sector-symmetric resting state it preserves the unsigned mass but reverses J, creates stiffness potential, and sends a positive admissible state outside the admissible cone. Mass can sit quietly in a neutral rest while the dual image is energetically charged and inadmissible — linking inertia bookkeeping to the same dual structure that defines charge conjugation, without identifying the two stories.反粒子の話で使う時間反転の双対写像（第 5 章）は、質量と不整合に異なる働きをします。完全に空の配置だけを固定し、そこでのみ質量は消えます。セクター対称の静止状態では符号なし質量を保ち、J を反転し、硬さポテンシャルを生み、正の許容状態を許容錐の外へ送ります。質量は中性の静止に静かに載り、双対像はエネルギーをもち許容外 — 慣性の台帳を荷電共役を定める同じ双対構造に結びつけますが、二つの物語を同一視はしません。

DST does not yet derive the numerical value of the mass coefficient in laboratory units, nor a mass gap from leaving a sector-symmetric rest state; it locates where unsigned mass can sit while mismatch and acceleration vanish.DST は、実験室単位での質量係数の数値も、セクター対称の静止から離れることによる質量ギャップも、まだ導いていません。不整合と加速度が消えるとき、符号なし質量がどこに載りうるかを示す、という内容です。

The ceiling does real work elsewhere in the repository. In the gravity track it is read as a finite redshift floor, so a one-way horizon (A = 0) does not form on that chart, and a light ray that would be captured classically turns around and comes back. When the same discrete height lattice is read as a Planck-mass ratio, the normalised mismatch has a separate gravitational floor (16/3)αG for a mass m — not the electromagnetic fine-structure constant α. In the number-theory track, a shared “no-go” theorem says no seed can be amplified past this ceiling.この上限はリポジトリの他の部分で重要な役割を果たします。重力の分野では有限の赤方偏移の下限として読まれ、その座標系では一方通行の地平（A = 0）ができません。古典的には捕らわれるはずの光線も、内部で向きを変えて戻ってきます。同じ離散の高さ格子をプランク質量比として読むと、正規化された不整合には質量 m に対する別の重力の下限 (16/3)αG があります。これは電磁気の微細構造定数 α とは別物です。数論の分野では、「どんな種もこの上限を超えて増幅できない」という共通の不可能定理になります。

Placing boosts on a compact 2π-torus, with admissibility on top, is the modelling choice the theory builds on.ブーストを周期 2π のトーラス上に置き、その上に許容性を課すことが、この理論の出発点となるモデル化です。
